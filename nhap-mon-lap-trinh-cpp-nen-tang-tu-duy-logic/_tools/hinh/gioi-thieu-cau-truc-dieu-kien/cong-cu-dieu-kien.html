Năm công cụ điều kiện sẽ học trong C++

Cùng một ý "nếu... thì...", chọn công cụ phù hợp với số ngã rẽ

if
Một nhánh: chỉ làm khi điều kiện đúng.
if (hp <= 0) { Game Over }
if...else
Hai ngã rẽ: đúng đi đường A, sai đi đường B.
if (diem >= 5) { DAU } else { ROT }
if...else if...else
Nhiều ngã rẽ liên tiếp, ví dụ xếp loại.
if (d >= 8) { Gioi } else if (d >= 6.5) { Kha } else { Trung binh }
switch case
Nhiều lựa chọn cụ thể, ví dụ menu 1, 2, 3.
switch (chon) { case 1: ... break; case 2: ... break; }
?: (ba ngôi)
Viết tắt gọn của if...else.
ketQua = (diem >= 5) ? "DAU" : "ROT";
Bài này chỉ cần biết tên và mục đích. Mỗi công cụ có một bài riêng ở phía sau.
