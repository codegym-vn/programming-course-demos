VS Code và MinGW: hai phần phải cài đủ

Một chiếc xe cần có cả vỏ và động cơ

VS Code

Vỏ xe: trình soạn thảo
  • Nơi gõ và lưu code
  • Gợi ý code, tô màu cú pháp
  • Có Terminal và nút Play ▷
  • Không tự biết biên dịch C++
+

MinGW (g++)

Động cơ: trình biên dịch
  • Dịch code C++ thành mã máy
  • Sinh ra tệp .exe để chạy
  • Phải nằm trong PATH thì máy mới tìm thấy
  • Không có chỗ để soạn code
Cài đủ cả hai: gõ code trong VS Code, g++ dịch ra hello.exe, rồi chạy.
