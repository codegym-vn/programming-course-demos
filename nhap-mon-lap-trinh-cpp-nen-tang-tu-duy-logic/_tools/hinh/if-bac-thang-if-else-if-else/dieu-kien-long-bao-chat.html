Điều kiện lỏng "bao" điều kiện chặt

Điểm 9 thỏa cả hai điều kiện; điều kiện nào đứng trên thì thắng

diem >= 5.0 (lỏng)
diem >= 8.0 (chặt)
diem = 9
05.08.010

Sai thứ tự: lỏng đứng trên

  1. diem >= 5.0 → đúng, in "Dat"
  2. diem >= 8.0 → không bao giờ được xét

Kết quả sai, nhưng không có lỗi biên dịch.

Đúng thứ tự: chặt đứng trên

  1. diem >= 8.0 → đúng, in "Xuat sac"
  2. diem >= 5.0 → không cần xét

Điều kiện khó thỏa mãn nhất đặt lên trước.
