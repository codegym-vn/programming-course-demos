Giải phẫu một chương trình C++

Năm phần của bộ khung mà chương trình C++ nào cũng có

1#include <iostream>
2using namespace std;
3int main() {
4cout << "Hello!";
5return 0;
}
1. Thư việnNạp công cụ nhập/xuất (cout, cin) trước khi dịch.
2. Không gian tênCho phép viết cout thay vì std::cout.
3. Hàm main() — cửa vàoChương trình luôn bắt đầu chạy từ đây.
4. Lệnh thực thiCác việc chương trình làm, chạy lần lượt từ trên xuống.
5. Kết thúcreturn 0 báo cho hệ điều hành: chạy xong, không lỗi.
