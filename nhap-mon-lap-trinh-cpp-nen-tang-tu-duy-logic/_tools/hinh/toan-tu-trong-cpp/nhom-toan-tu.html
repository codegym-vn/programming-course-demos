Năm nhóm toán tử trong C++

Ví dụ với a = 10, b = 3 (nhóm gán và tăng giảm dùng x = 5)

Nhóm
Toán tử
Ví dụ và kết quả
Số họctính toán
+ - * / %
a / b → 3
a % b → 1
Gánbỏ giá trị vào biến
= += -= *= %=
x += 3 → x = x + 3 → 8
So sánhkết quả luôn 1 hoặc 0
== != > < >= <=
a == b → 0 (sai)
a != b → 1 (đúng)
Logickết hợp điều kiện
&& || !
(a > 5 && b > 5) → 0
(a > 5 || b > 5) → 1
Tăng giảmcộng hoặc trừ 1
++ --
x++ và ++x đều làm x thành 6
nhưng giá trị dùng ngay khác nhau
