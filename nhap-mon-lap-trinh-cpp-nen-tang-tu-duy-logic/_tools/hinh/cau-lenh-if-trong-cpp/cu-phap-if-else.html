Các phần của if...else

Mỗi phần có một nhiệm vụ riêng

1if (diem >= 5) {
2// chạy khi điều kiện ĐÚNG
3} else {
4// chạy khi điều kiện SAI
}
1. Từ khóa if và điều kiệnĐiều kiện đặt trong ngoặc tròn, phải cho ra Đúng hoặc Sai.
2. Khối lệnh của ifCặp { } gom các lệnh chỉ chạy khi điều kiện Đúng.
3. elseKhông có điều kiện riêng, tự chạy khi điều kiện của if Sai.
4. Khối lệnh của elseChỉ chạy khi điều kiện Sai. Có thể bỏ cả else nếu không cần.
