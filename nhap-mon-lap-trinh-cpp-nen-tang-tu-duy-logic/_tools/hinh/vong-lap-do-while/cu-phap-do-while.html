Cú pháp do...while: làm trước, kiểm tra sau

Thân vòng lặp luôn chạy ít nhất 1 lần

do {
  // thân: chạy ngay lần đầu
  // rồi lặp lại nếu điều kiện đúng
} while (điều_kiện);
1. Làm trướcMáy vào thẳng thân, không hỏi han gì.
2. Kiểm tra sauĐúng thì quay lại bước 1, sai thì dừng.
3. Đừng quên dấu ;do...while bắt buộc có ; sau điều kiện.
while giống soát véKiểm tra vé trước, rồi mới được vào cổng.
do...while giống buffetVào ăn trước, tính tiền sau.
