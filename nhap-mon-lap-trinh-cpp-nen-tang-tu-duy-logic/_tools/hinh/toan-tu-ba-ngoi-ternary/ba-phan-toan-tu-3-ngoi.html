Ba phần của toán tử ?:

Cách đọc: "điều kiện này có đúng không? Đúng thì lấy A, sai thì lấy B"

(number % 2 == 0)?"So Chan":"So Le"
1. Điều kiệncâu hỏi Đúng/Sai
2. Giá trị nếu đúngđứng sau dấu ?
3. Giá trị nếu saiđứng sau dấu :
if (number % 2 == 0) {
  result = "So Chan";
} else {
  result = "So Le";
}

Hai cách viết cho cùng kết quả. Điểm khác: ?: là một biểu thức, nó cho ra một giá trị, nên đặt được sau dấu = hoặc trong cout.
