# Câu Lệnh If Trong C++

## 1. Mục Tiêu Bài Học

- Hiểu bản chất: nắm được cách máy tính xử lý logic Đúng/Sai để tự động chọn luồng chạy code.
- Nắm vững cú pháp: viết đúng câu lệnh `if` (điều kiện đơn) và `if...else` (điều kiện rẽ nhánh) theo chuẩn C++.
- Tránh được lỗi sai phổ biến: nhận biết tầm quan trọng của dấu ngoặc nhọn `{ }` và các lỗi logic thường gặp khi thiếu chúng.
- Ứng dụng được vào các bài toán thực tế: kiểm tra chẵn/lẻ, đậu/rớt, đăng nhập thành công/thất bại.

## 2. Giới Thiệu

Ở các bài học trước, mọi chương trình bạn viết đều chạy theo một đường thẳng — từ dòng đầu tiên đến dòng cuối cùng, không bỏ sót bất kỳ dòng nào. Nhưng thực tế cuộc sống luôn có sự lựa chọn: nếu trời mưa, bạn đi taxi; nếu trời nắng, bạn đi xe máy.

Để chương trình có thể "suy nghĩ" và đưa ra lựa chọn giống con người, C++ cung cấp cho chúng ta **Cấu trúc điều kiện** — công cụ giúp chương trình tự động kiểm tra dữ liệu và quyết định sẽ chạy dòng code nào. Trong bài này, chúng ta sẽ đi sâu vào công cụ điều kiện cơ bản và quan trọng nhất: câu lệnh `if` và `if...else`.

## 3. Khái Niệm

- `if` **(Nếu)**: cấu trúc điều kiện đơn giản nhất — chỉ thực hiện một khối lệnh khi điều kiện là Đúng (true); nếu Sai, chương trình bỏ qua và chạy tiếp các dòng phía sau.
- `if...else` **(Nếu... ngược lại)**: cấu trúc điều kiện có hai nhánh rõ ràng — nhánh 1 chạy khi điều kiện Đúng, nhánh 2 (`else`) chạy khi điều kiện Sai.
- **Khối lệnh (Block)**: một hoặc nhiều dòng lệnh được nhóm lại với nhau, thường được bao bọc bởi cặp dấu ngoặc nhọn `{ }`.
- **Thụt đầu dòng (Indentation)**: quy ước trình bày code bằng cách lùi vào một khoảng (thường là 1 Tab hoặc 4 dấu cách) cho các dòng lệnh nằm bên trong `{ }`, giúp code dễ đọc và dễ theo dõi cấu trúc.

## 4. Giải Thích

### 4.1. Cấu Trúc if (Nếu...)

Đây là dạng đơn giản nhất. Máy tính chỉ thực hiện hành động khi điều kiện là Đúng (True); nếu Sai, nó sẽ lờ đi và chạy tiếp các lệnh phía sau.

**Cú pháp:**

```cpp
if (điều_kiện)
{
    // Khối lệnh này chỉ chạy nếu điều_kiện là ĐÚNG (true)
}
```

### 4.2. Cấu Trúc if...else (Nếu... Ngược Lại...)

Dùng khi bạn muốn chia chương trình thành 2 ngã rẽ rõ ràng: điều kiện Đúng đi đường A, Sai đi đường B — không có trường hợp thứ ba.

**Cú pháp:**

```cpp
if (điều_kiện)
{
    // NHÁNH 1: Chạy khi điều kiện ĐÚNG
}
else
{
    // NHÁNH 2: Chạy khi điều kiện SAI
}
```

### 4.3. Ba Quy Tắc Quan Trọng Cần Ghi Nhớ

**1. Điều kiện phải trả về True/False**

Biểu thức trong cặp ngoặc tròn `( )` sau chữ `if` phải là một phép so sánh hoặc phép logic, trả về kết quả Đúng hoặc Sai.

- Ví dụ đúng: `if (a > b)`, `if (score == 100)`.
- Ví dụ sai: `if (a = 10)` — đây là phép **gán**, không phải phép **so sánh** (lỗi kinh điển đã học ở bài Toán tử). C++ vẫn biên dịch được vì giá trị gán (10) khác 0 nên luôn được coi là Đúng.

**2. Khối lệnh và dấu ngoặc nhọn** `{ }`

Nếu sau `if` hoặc `else` bạn muốn thực hiện nhiều hơn 1 dòng lệnh, bạn **bắt buộc** phải kẹp chúng trong cặp dấu `{ }`. Nếu chỉ có đúng 1 dòng lệnh, C++ cho phép bỏ `{ }`, nhưng lời khuyên chân thành là **hãy luôn dùng** `{ }` để code rõ ràng và tránh lỗi khi sửa chữa sau này — chi tiết về lỗi này sẽ được minh họa cụ thể ở phần Ví dụ.

**3. Thụt đầu dòng (Indentation)**

Luôn thụt vào cho các dòng code nằm bên trong `{ }`. Việc này giúp bạn (và người khác đọc code của bạn) nhìn vào là biết ngay đoạn code đó thuộc về điều kiện nào — mặc dù về mặt kỹ thuật, C++ không bắt buộc thụt đầu dòng để chạy đúng, nhưng thiếu nó sẽ khiến code cực kỳ dễ gây hiểu lầm (xem Ví dụ 3).

## 5. Ví Dụ

Toàn bộ output dưới đây là kết quả khi biên dịch và chạy thử bằng g++.

### Ví dụ 1: Kiểm tra tuổi để bán vé xem phim 18+ (Mục tiêu: nắm cú pháp if)

```cpp
int age = 20;
// Máy tính hỏi: age có lớn hơn hoặc bằng 18 không?
if (age >= 18) {
    cout << "Moi ban vao xem phim!" << endl;
}
```

**Output khi** `age = 20`**:**

```
Moi ban vao xem phim!
```

Nếu đổi `age = 15`, điều kiện `15 >= 18` là Sai — chương trình sẽ hoàn toàn bỏ qua dòng `cout` bên trong `if`, không in ra bất kỳ thông báo nào, rồi tiếp tục chạy các dòng lệnh phía sau.

### Ví dụ 2: Kiểm tra học sinh Đậu hay Rớt (Mục tiêu: nắm cú pháp if...else)

```cpp
int diem = 4;
if (diem >= 5) {
    cout << "Chuc mung! Ban da DAU." << endl;
} else {
    cout << "Rat tiec! Ban da ROT." << endl;  // Máy chạy vào đây vì 4 >= 5 là Sai
}
```

**Output:**

```
Rat tiec! Ban da ROT.
```

Vì điểm chuẩn là 5, và `4 >= 5` cho kết quả Sai, chương trình tự động nhảy vào nhánh `else` để in ra thông báo tương ứng — đây chính là ví dụ điển hình cho việc "chọn 1 trong 2 con đường".

### Ví dụ 3: Lỗi kinh điển khi thiếu dấu ngoặc nhọn { } (Mục tiêu: tránh lỗi sai, hiểu tầm quan trọng của { })

```cpp
int diem = 3;  // Điểm thấp, KHÔNG lớn hơn 5
if (diem > 5)
    cout << "Dau roi!" << endl;
    cout << "Di choi thoi!" << endl;  // Dòng này có thuộc về if không?
```

**Output (dù** `diem = 3`**, không thỏa điều kiện** `diem > 5`**):**

```
Di choi thoi!
```

Đây là minh chứng rõ ràng nhất cho quy tắc "không có `{ }` thì `if` chỉ quản lý đúng 1 dòng lệnh ngay sau nó". Dòng `cout << "Di choi thoi!"` nằm ngoài phạm vi của `if` (dù cách trình bày thụt đầu dòng khiến nó trông giống như đang nằm bên trong), nên nó **luôn được in ra** bất kể điều kiện đúng hay sai. Đáng chú ý, khi biên dịch với cờ cảnh báo `-Wall`, trình biên dịch g++ phát hiện và cảnh báo lỗi này:

```
warning: this 'if' clause does not guard...
note: ...this statement, but the latter is misleadingly indented as if it were guarded by the 'if'
```

Đây là lý do quan trọng nhất khiến việc luôn dùng `{ }`, kể cả khi chỉ có 1 dòng lệnh, trở thành một thói quen bắt buộc của lập trình viên chuyên nghiệp.

### Ví dụ 4: Kiểm tra số Chẵn/Lẻ (Mục tiêu: ứng dụng thực tế)

```cpp
int number = 7;
if (number % 2 == 0) {
    cout << "So chan" << endl;
} else {
    cout << "So le" << endl;
}
```

**Output:**

```
So le
```

Ví dụ này kết hợp kiến thức đã học ở bài Toán tử — dùng phép chia lấy dư (`%`) để kiểm tra: nếu một số chia cho 2 mà dư 0, đó là số chẵn; ngược lại là số lẻ.

### Ví dụ 5: Đăng nhập hệ thống — so sánh mật khẩu (Mục tiêu: ứng dụng thực tế)

```cpp
#include <string>
// ...
string dbPassword = "abc123";
string inputPassword = "abc123";

if (inputPassword == dbPassword) {
    cout << "Dang nhap thanh cong!" << endl;
} else {
    cout << "Sai mat khau, vui long thu lai." << endl;
}
```

**Output với hai trường hợp:**

```
inputPassword = "abc123" -> Dang nhap thanh cong!
inputPassword = "wrong" -> Sai mat khau, vui long thu lai.
```

Đây là logic nền tảng đứng sau mọi hệ thống đăng nhập thực tế — dù giao diện có phức tạp đến đâu, cốt lõi vẫn luôn là một phép so sánh chuỗi (`string`) đơn giản bằng `if...else`.

## 6. Phần Chú Ý Và Lỗi Hay Gặp

- **Nhầm lẫn** `=` **(gán) và** `==` **(so sánh) trong điều kiện** `if`: viết `if (a = 10)` thay vì `if (a == 10)` không hề báo lỗi biên dịch, nhưng sẽ âm thầm gán giá trị 10 cho `a` và luôn cho kết quả Đúng — đây là lỗi logic cực kỳ khó phát hiện.
- **Bỏ quên dấu ngoặc nhọn** `{ }` **khi có nhiều hơn 1 dòng lệnh**: như đã minh họa ở Ví dụ 3, dòng lệnh thứ hai trở đi sẽ nằm ngoài phạm vi kiểm soát của `if`, luôn được thực thi bất kể điều kiện đúng hay sai. Luôn dùng `{ }` để tránh rủi ro này, kể cả khi hiện tại chỉ có 1 dòng lệnh.
- **Tin tưởng hoàn toàn vào thụt đầu dòng để xác định phạm vi của** `if`: thụt đầu dòng chỉ mang tính trực quan cho người đọc, không có giá trị về mặt cú pháp đối với trình biên dịch. Đừng để cách trình bày đánh lừa bạn về phạm vi thực sự của khối lệnh.
- **Đặt dấu** `;` **ngay sau** `if (...)`: dấu chấm phẩy làm thân của `if` thành rỗng, còn khối `{ }` phía sau luôn chạy dù điều kiện đúng hay sai.
- **Quên rằng** `else` **không cần điều kiện riêng**: `else` luôn đi kèm với `if` ngay phía trước nó, và tự động chạy khi điều kiện của `if` đó là Sai — bạn không thể (và không cần) viết điều kiện cho `else`.
- **Nhầm lẫn phạm vi áp dụng giữa** `if` **(1 nhánh) và** `if...else` **(2 nhánh)**: nếu bạn chỉ cần xử lý trường hợp Đúng và không cần làm gì khi Sai, dùng `if` đơn thuần là đủ; chỉ dùng `if...else` khi thực sự cần xử lý cả hai trường hợp khác nhau, tránh viết dư thừa `else { }` rỗng không cần thiết.
