# Vòng Lặp Do...While

## 1. Mục Tiêu Bài Học

- Hiểu bản chất: tại sao vòng lặp này luôn chạy ít nhất 1 lần, dù điều kiện có sai ngay từ đầu.
- Phân biệt được sự khác nhau tinh tế giữa `while` và `do...while`.
- Ứng dụng được vào việc viết Menu chương trình và các chức năng nhập liệu bắt buộc.
- Tránh được lỗi phổ biến nhất: quên dấu chấm phẩy ở cuối câu lệnh `do...while`.
- Quan sát `while` và `do...while` chạy song song bằng hoạt động mô phỏng.

## 2. Giới Thiệu

Ở bài `while`, bạn đã biết nó hoạt động như một "người gác cổng" — kiểm tra điều kiện trước, rồi mới quyết định có cho chạy hay không. Nhưng có những tình huống mà cách làm này lại bất tiện: hãy nghĩ đến một Menu chương trình — bạn chắc chắn muốn **hiển thị Menu ít nhất 1 lần** để người dùng nhìn thấy các lựa chọn, trước khi có thể hỏi họ có muốn thoát hay không. Nếu dùng `while` thông thường, bạn sẽ phải tìm cách "lừa" điều kiện ban đầu để nó luôn đúng trong lần đầu tiên — khá lằng nhằng.

`do...while` sinh ra để giải quyết đúng vấn đề này. Nó đảo ngược thứ tự so với `while`: **làm trước, kiểm tra sau** — đảm bảo khối lệnh bên trong luôn được chạy ít nhất 1 lần, bất kể điều kiện đúng hay sai ngay từ đầu.

## 3. Khái Niệm

- `do...while`: cấu trúc lặp hoạt động theo nguyên tắc "thực hiện hành động trước, kiểm tra điều kiện sau" — đảm bảo khối lệnh bên trong luôn được thực thi ít nhất 1 lần.
- **Thứ tự hoạt động**: chạy thẳng vào khối lệnh `do` trước (không cần hỏi han gì cả), sau đó mới kiểm tra điều kiện ở `while` để quyết định có lặp lại hay dừng.
- **Dấu chấm phẩy bắt buộc**: khác với `while` thông thường, cú pháp `do...while` yêu cầu bắt buộc phải có dấu `;` ngay sau phần điều kiện `while (điều_kiện)`.

## 4. Giải Thích

### 4.1. Cú Pháp

```cpp
do {
    // Khối lệnh này sẽ chạy ngay lập tức lần đầu tiên
    // Sau đó lặp lại nếu điều kiện bên dưới đúng
} while (dieu_kien);   // <--- CHÚ Ý DẤU CHẤM PHẨY (;) Ở ĐÂY
```

### 4.2. Luồng Hoạt Động

1. Chạy thẳng vào khối lệnh `do` (không cần hỏi han gì cả).
2. Gặp `while`, kiểm tra điều kiện.
3. Nếu Đúng (`true`) → quay lại bước 1.
4. Nếu Sai (`false`) → dừng vòng lặp, đi tiếp xuống dưới.

### 4.3. So Sánh: while và do...while

| Đặc điểm | `while` (kiểm tra trước) | `do...while` (làm trước) |
|---|---|---|
| Thứ tự | Kiểm tra điều kiện → Chạy lệnh | Chạy lệnh → Kiểm tra điều kiện |
| Số lần chạy tối thiểu | 0 lần (nếu điều kiện sai ngay từ đầu) | 1 lần (luôn luôn chạy 1 lần đầu) |
| Ví dụ đời thường | Soát vé trước khi vào cổng | Ăn quán buffet (vào ăn trước, trả tiền sau) |
| Khi nào dùng? | Khi điều kiện có thể sai ngay từ đầu | Khi muốn hiển thị Menu hoặc bắt nhập liệu |

## 5. Ví Dụ

Toàn bộ output và thông báo lỗi dưới đây đã được biên dịch, chạy thử thực tế bằng g++ để đảm bảo tính chính xác. Mỗi đoạn code đặt trong hàm `main()` của một chương trình có `#include <iostream>` và `using namespace std;`.

### Ví dụ 1: Chứng minh do...while luôn chạy ít nhất 1 lần (Mục tiêu: hiểu bản chất cốt lõi)

```cpp
int i = 100;   // Điều kiện sẽ SAI ngay từ đầu (100 không nhỏ hơn 5)
int lanChay = 0;
do {
    lanChay++;
    cout << "Da chay lan thu " << lanChay << ", i = " << i << endl;
} while (i < 5);
cout << "Tong so lan chay: " << lanChay << endl;
```

Kết quả trên màn hình:

```
Da chay lan thu 1, i = 100
Tong so lan chay: 1
```

Đây là bằng chứng rõ ràng nhất: dù `i = 100` khiến điều kiện `i < 5` Sai ngay từ đầu, khối lệnh bên trong `do` vẫn chạy đúng **1 lần** trước khi vòng lặp kiểm tra điều kiện và dừng lại — khác hẳn với `while` thông thường, nơi khối lệnh không chạy lần nào trong trường hợp tương tự.

### Ví dụ 2: Nhập số dương — bắt buộc nhập ít nhất 1 lần (Mục tiêu: ứng dụng nhập liệu)

```cpp
int n;
do {
    cout << "Nhap mot so duong: ";
    cin >> n;
} while (n <= 0);   // Nếu nhập sai (<= 0) thì bắt quay lại nhập tiếp
cout << "Ban da nhap: " << n << endl;
```

Khi lần lượt nhập `-5`, rồi `-2`, rồi `9`, màn hình hiện:

```
Nhap mot so duong: -5
Nhap mot so duong: -2
Nhap mot so duong: 9
Ban da nhap: 9
```

Đây là ứng dụng rất tự nhiên: chương trình **bắt buộc** phải hỏi người dùng ít nhất 1 lần (vì chưa hỏi thì làm sao biết `n` hợp lệ hay không), rồi mới kiểm tra để quyết định có cần hỏi lại hay không.

### Ví dụ 3: Menu chương trình game — ứng dụng phổ biến nhất (Mục tiêu: ứng dụng Menu)

```cpp
int choice;
do {
    // 1. Hiển thị Menu trước
    cout << "\n--- MENU GAME ---" << endl;
    cout << "1. Start Game\n2. Options\n3. Exit" << endl;
    cout << "Chon chuc nang: ";
    cin >> choice;

    // 2. Xử lý lựa chọn
    if (choice == 1)
        cout << "Dang vao game..." << endl;
    else if (choice == 2)
        cout << "Mo cai dat..." << endl;

    // 3. Nếu chưa chọn 3 (Thoát) thì lặp lại Menu
} while (choice != 3);
cout << "Da thoat chuong trinh." << endl;
```

Khi lần lượt chọn `1`, rồi `2`, rồi `3`, màn hình hiện:

```
--- MENU GAME ---
1. Start Game
2. Options
3. Exit
Chon chuc nang: 1
Dang vao game...

--- MENU GAME ---
1. Start Game
2. Options
3. Exit
Chon chuc nang: 2
Mo cai dat...

--- MENU GAME ---
1. Start Game
2. Options
3. Exit
Chon chuc nang: 3
Da thoat chuong trinh.
```

Menu luôn được hiển thị trước tiên — đây chính là lý do `do...while` là lựa chọn tự nhiên và phù hợp nhất cho mọi chương trình dạng Menu. Phần xử lý lựa chọn (`if...else if`) đặt **trước** dòng kiểm tra `while (choice != 3)`, để lựa chọn được xử lý ngay trong lượt đó trước khi vòng lặp quyết định tiếp tục hay dừng.

### Ví dụ 4: Lỗi quên dấu chấm phẩy — thông báo lỗi biên dịch thật (Mục tiêu: tránh lỗi cú pháp)

```cpp
int i = 1;
do {
    cout << i;
    i++;
} while (i < 5)   // THIẾU dấu chấm phẩy ở cuối!
return 0;
```

Thông báo lỗi biên dịch của g++:

```
error: expected ';' before 'return'
```

Đây là lỗi cú pháp rất phổ biến, vì `while` thông thường không cần dấu `;` sau phần điều kiện, nhưng `do...while` thì **bắt buộc phải có**. Trình biên dịch không báo lỗi ngay tại chỗ thiếu `;`, mà báo ở dòng **kế tiếp** (`return 0;`) — điều khiến nhiều người mới học bối rối, vì lỗi thực sự nằm ở dòng phía trên dòng được báo.

## 6. Phần Chú Ý Và Lỗi Hay Gặp

- **Quên dấu chấm phẩy** `;` **sau** `while (điều_kiện)`: đây là lỗi cú pháp phổ biến nhất riêng của `do...while`. Ghi nhớ: "**do ... while (...);**" — luôn có dấu chấm phẩy ở cuối cùng.
- **Quên cập nhật biến điều khiển bên trong khối** `do`: giống hệt lỗi ở `while` và `for`, nếu biến trong điều kiện không được thay đổi bên trong vòng lặp, chương trình sẽ rơi vào vòng lặp vô hạn. Khi thử code mà bị treo, hãy dừng chương trình bằng `Ctrl + C`.
- **Khai báo biến điều kiện bên trong khối** `do`: biến dùng trong `while (...)` phải được khai báo **bên ngoài** khối `do { }`. Biến khai báo bên trong `{ }` chỉ tồn tại trong khối đó, nên điều kiện ở cuối không nhìn thấy nó và trình biên dịch báo lỗi.
- **Nhầm lẫn giữa** `while` **và** `do...while` **khi bài toán cần chạy 0 lần**: nếu bài toán có thể **không chạy lần nào** khi điều kiện sai ngay từ đầu (ví dụ: chỉ xử lý khi có dữ liệu), hãy dùng `while` — dùng nhầm `do...while` sẽ khiến chương trình chạy dư 1 lần không mong muốn.
- **Quên rằng đây là công cụ lý tưởng cho Menu và nhập liệu bắt buộc**: nhiều người mới học vẫn cố dùng `while` kèm các "mẹo" để giả lập việc chạy trước 1 lần (ví dụ gán sẵn giá trị giả cho biến), trong khi `do...while` đã được thiết kế sẵn để giải quyết đúng vấn đề này một cách tự nhiên hơn nhiều.
