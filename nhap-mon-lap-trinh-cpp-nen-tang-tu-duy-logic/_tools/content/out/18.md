# Vòng Lặp While

## 1. Mục Tiêu Bài Học

- Hiểu bản chất: `while` hoạt động như một "người gác cổng" — chỉ cho phép chạy tiếp khi điều kiện còn Đúng.
- Phân biệt được khi nào dùng `for` (biết trước số lần lặp), khi nào dùng `while` (chưa biết trước số lần lặp).
- Ứng dụng được vào việc viết code kiểm tra nhập liệu — bắt người dùng nhập lại cho đến khi đúng.
- Tránh được lỗi phổ biến nhất khi dùng `while`: vòng lặp vô hạn (Infinite Loop).
- Quan sát từng bước người gác cổng kiểm tra điều kiện bằng hoạt động mô phỏng.

## 2. Giới Thiệu

Ở bài vòng lặp `for`, bạn đã quen với việc biết trước chính xác số lần cần lặp — ví dụ chạy đúng 10 vòng, in đúng 100 dòng. Nhưng thực tế không phải lúc nào cũng "biết trước" như vậy: bạn không thể biết trước người dùng sẽ nhập sai mật khẩu 1 lần hay 10 lần, cũng không biết trước một cục pin sẽ tụt bao nhiêu % sau mỗi lần sử dụng.

Đây chính là lúc **vòng lặp** `while` phát huy sức mạnh. Nó không quan tâm đến "số lần", mà chỉ quan tâm đến một điều duy nhất: **điều kiện này còn Đúng hay không?** Chừng nào điều kiện còn Đúng, `while` sẽ tiếp tục chạy; ngay khi điều kiện chuyển sang Sai, nó lập tức dừng lại.

## 3. Khái Niệm

- `while (điều_kiện)`: cấu trúc lặp lại một đoạn mã chừng nào điều kiện còn Đúng (`true`); dừng ngay khi điều kiện chuyển sang Sai (`false`).
- **Quy tắc hoạt động 3 bước**: (1) kiểm tra điều kiện, (2) nếu Đúng thì chạy khối lệnh bên trong rồi quay lại bước 1, (3) nếu Sai thì dừng ngay lập tức.
- **Biến điều khiển**: biến xuất hiện trong điều kiện của `while`, quyết định vòng lặp sẽ tiếp tục hay dừng lại — biến này bắt buộc phải được thay đổi ở đâu đó bên trong vòng lặp.

## 4. Giải Thích

### 4.1. Cú Pháp

```cpp
while (dieu_kien) {
    // Khối lệnh này sẽ chạy lặp lại
    // LƯU Ý: bên trong này phải có lệnh làm thay đổi điều kiện
}
```

### 4.2. So Sánh: Khi Nào Dùng for, Khi Nào Dùng while?

| Đặc điểm | Vòng lặp `for` | Vòng lặp `while` |
|---|---|---|
| Số lần lặp | Biết trước (ví dụ: 10 lần, 100 lần) | Chưa biết trước (phụ thuộc vào một điều kiện) |
| Ví dụ đời thường | "Chạy 5 vòng sân vận động" | "Chạy cho đến khi mệt thì nghỉ" |
| Ứng dụng chính | Duyệt danh sách, đếm số | Kiểm tra mật khẩu, đợi người dùng nhập đúng, vòng lặp trò chơi |

## 5. Ví Dụ

Toàn bộ output dưới đây đã được biên dịch và chạy thử thực tế bằng g++ để đảm bảo tính chính xác. Mỗi đoạn code đặt trong hàm `main()` của một chương trình có `#include <iostream>`, `#include <string>` và `using namespace std;`.

### Ví dụ 1: Mô phỏng vòng lặp for bằng while — đếm số (Mục tiêu: hiểu bản chất while, so sánh với for)

Mặc dù `while` mạnh về việc "chưa biết trước", nó vẫn hoàn toàn làm được việc đếm số giống `for`:

```cpp
int i = 1;            // 1. Khởi tạo bên ngoài
while (i <= 5) {      // 2. Kiểm tra điều kiện
    cout << i << " ";
    i++;              // 3. Cập nhật (QUAN TRỌNG: quên dòng này là lỗi)
}
```

Kết quả trên màn hình:

```
1 2 3 4 5
```

Khác với `for` (gói cả 3 bước vào chung 1 dòng), `while` tách riêng 3 bước Khởi tạo – Kiểm tra – Cập nhật ra thành 3 vị trí khác nhau trong code — đây cũng chính là lý do khiến `while` dễ bị quên bước cập nhật hơn `for`.

### Ví dụ 2: Kiểm tra nhập liệu — bắt nhập lại số dương (Mục tiêu: ứng dụng thực tế nổi bật nhất của while)

```cpp
int n;
cout << "Nhap so nguyen duong: ";
cin >> n;

// Chừng nào n còn nhỏ hơn hoặc bằng 0 (sai yêu cầu) -> bắt làm lại
while (n <= 0) {
    cout << "Sai roi! Phai nhap so duong. Nhap lai: ";
    cin >> n;
}
cout << "Cam on, ban da nhap: " << n << endl;
```

Khi lần lượt nhập `-3`, rồi `-10`, rồi `7`, màn hình hiện:

```
Nhap so nguyen duong: -3
Sai roi! Phai nhap so duong. Nhap lai: -10
Sai roi! Phai nhap so duong. Nhap lai: 7
Cam on, ban da nhap: 7
```

Đây chính là ví dụ kinh điển nhất cho việc "không biết trước số lần lặp" — người dùng có thể nhập sai 0 lần, 2 lần, hay 100 lần, và `while` xử lý được tất cả các trường hợp đó bằng cùng một đoạn code duy nhất. Lưu ý: ví dụ này chỉ an toàn khi người dùng nhập số; nếu gõ chữ, `cin` bị lỗi và cần xử lý thêm (kiến thức nâng cao, chưa học ở bài này).

### Ví dụ 3: Đăng nhập mật khẩu (Mục tiêu: ứng dụng thực tế)

```cpp
string pass;
cout << "Nhap mat khau cua ban: ";
cin >> pass;

// Lặp lại mãi nếu mật khẩu khác "123456"
while (pass != "123456") {
    cout << "Mat khau sai! Vui long nhap lai: ";
    cin >> pass;
}
cout << "Dang nhap thanh cong!" << endl;
```

Khi lần lượt nhập `abc`, rồi `999999`, rồi `123456`, màn hình hiện:

```
Nhap mat khau cua ban: abc
Mat khau sai! Vui long nhap lai: 999999
Mat khau sai! Vui long nhap lai: 123456
Dang nhap thanh cong!
```

### Ví dụ 4: Mô phỏng mức pin điện thoại (Mục tiêu: hiểu cách điều kiện thay đổi dần theo mỗi lượt)

```cpp
int pin = 100;
// Chỉ hoạt động khi pin còn trên 20%
while (pin > 20) {
    cout << "Dang su dung... Pin con: " << pin << "%" << endl;
    pin -= 20;   // Giả sử mỗi lần dùng tụt 20%
}
cout << "Pin yeu (" << pin << "%). Vui long cam sac!" << endl;
```

Kết quả trên màn hình:

```
Dang su dung... Pin con: 100%
Dang su dung... Pin con: 80%
Dang su dung... Pin con: 60%
Dang su dung... Pin con: 40%
Pin yeu (20%). Vui long cam sac!
```

Vòng lặp dừng lại đúng lúc `pin` giảm xuống còn `20` — vì điều kiện là `pin > 20` (lớn hơn, không phải lớn hơn hoặc bằng), nên khi `pin` đúng bằng `20`, điều kiện đã Sai và thông báo "Pin yếu" được in ra thay vì tiếp tục vòng lặp.

### Xem các ví dụ chạy từng bước

Mô phỏng dưới đây chạy lại Ví dụ 4, Ví dụ 2 và lỗi quên `i++`. Bên trái là mã nguồn, bên phải là màn hình, hình "người gác cổng" và bảng theo dõi. Bấm **Bước tiếp** để chạy từng dòng và để ý những điều mà chữ chưa nói hết:

- Tab **Pin điện thoại (100% đến 20%)**: thanh pin tụt dần 20% mỗi lượt, và bảng theo dõi ghi lại mỗi lần kiểm tra. Kết quả cuối cho thấy điều kiện được kiểm tra 5 lần nhưng thân chỉ chạy 4 lượt.
- Tab **Bắt nhập lại số dương**: hàng thẻ ghi các giá trị đã nhập, thẻ đỏ là giá trị bị từ chối (`-3`, `-10`), thẻ xanh là giá trị được chấp nhận (`7`).
- Tab **Quên i++ dẫn tới lặp vô hạn**: `i` đứng yên ở 1 trong khi bộ đếm lượt tăng vọt. Mô phỏng tự dừng ở 1000 lượt cho gọn (máy thật sẽ chạy mãi), rồi cho thấy kết quả sau khi thêm `i++`.

## 6. Phần Chú Ý Và Lỗi Hay Gặp

Lỗi phổ biến nhất khi dùng `while`: nếu điều kiện luôn luôn Đúng, chương trình sẽ chạy mãi mãi và treo. Khi thử code mà bị treo, hãy dừng chương trình bằng `Ctrl + C` trong terminal. Cả ba tình huống dưới đây đều biên dịch được và không có thông báo lỗi nào.

### Lỗi 1: Quên cập nhật biến điều kiện

```cpp
int i = 1;
while (i <= 5) {
    cout << i;
    // Lỗi: quên tăng i. i mãi mãi là 1, 1 luôn <= 5 -> lặp vô tận.
}
```

Biến `i` giữ nguyên giá trị `1` từ đầu đến cuối, điều kiện không bao giờ chuyển sang Sai, nên chương trình chỉ dừng khi bị ép dừng từ bên ngoài.

### Lỗi 2: Cập nhật sai hướng

```cpp
int i = 10;
while (i > 0) {
    cout << i;
    i++;   // Lỗi: i đang là 10, càng tăng thì càng lớn hơn 0 -> lặp vô tận.
}
```

Biến `i` có thay đổi, nhưng thay đổi theo hướng ra xa điểm dừng. Muốn đếm ngược về 0 thì phải dùng `i--`.

### Lỗi 3: Điều kiện sai ngay từ đầu

```cpp
int i = 10;
while (i < 5) {
    // Lỗi logic: 10 không nhỏ hơn 5.
    cout << i;
    i++;
}
```

Dòng `cout` bên trong hoàn toàn không được chạy, vì `i = 10` không thỏa điều kiện `i < 5` ngay từ lần kiểm tra đầu tiên.

**Ghi nhớ cuối bài:** dùng `while` khi bạn muốn nói với máy tính "cứ làm đi, chừng nào điều kiện này còn đúng thì đừng dừng lại". Nhưng trước khi chạy thử bất kỳ vòng lặp `while` nào, hãy luôn tự kiểm tra: **bên trong vòng lặp có dòng lệnh nào thực sự làm thay đổi điều kiện để tiến dần đến điểm dừng hay không** (như `i++`, `cin >> n`, `pin -= 20`)? Đây là câu hỏi duy nhất giúp bạn tránh được cả ba lỗi vừa nêu.
