# Cài Đặt Môi Trường Lập Trình C++ Với VS Code

### 1. Mục Tiêu Bài Học

Đây là hướng dẫn dành cho những bạn muốn một môi trường lập trình gọn nhẹ, hiện đại, phù hợp với cả những máy tính có cấu hình không quá mạnh. Sau khi hoàn thành bài học này, bạn sẽ:

- Hiểu được mô hình hoạt động: VS Code đóng vai trò "vỏ" (trình soạn thảo), còn MinGW đóng vai trò "lõi" (trình biên dịch).
- Cài đặt thành công Visual Studio Code cùng các Extension cần thiết cho lập trình C++.
- Cài đặt trình biên dịch g++ (MinGW) để máy tính có thể hiểu và chạy được mã nguồn C++.
- Cấu hình VS Code để biên dịch và debug code C++ một cách bài bản (không chỉ dừng ở việc chạy thử).
- Tự viết và chạy thành công chương trình C++ đầu tiên.
- Tự xử lý được các lỗi phổ biến khi mới cài đặt.

### 2. Tại Sao Chọn VS Code?

Trên thị trường có khá nhiều công cụ để lập trình C++ như Visual Studio, Code::Blocks, Dev-C++, CLion... Tuy nhiên, VS Code đang là lựa chọn phổ biến nhất hiện nay nhờ các ưu điểm sau:

- Siêu nhẹ: chỉ khoảng 100MB, tải và mở gần như tức thì. Trong khi đó Visual Studio bản đầy đủ nặng vài GB và cài đặt lâu.
- Đa năng: lập trình được C++, Python, Web, Java... chỉ cần thêm Extension, khác với Visual Studio vốn tối ưu chủ yếu cho hệ sinh thái Microsoft.
- Giao diện hiện đại, dễ tùy biến theme, icon, font chữ.
- Khởi động rất nhanh, phù hợp cho người mới học và người làm nhiều ngôn ngữ khác nhau.

**Lưu ý quan trọng:** VS Code giống như một chiếc "vỏ xe" — bản thân nó không biết biên dịch C++. Muốn "xe chạy được", ta cần lắp thêm "động cơ", chính là Compiler (trình biên dịch). Vì vậy trong bài này, chúng ta sẽ cài đặt cả hai thành phần:

- MinGW (g++) — động cơ, chịu trách nhiệm dịch code C++ sang ngôn ngữ máy.
- VS Code — vỏ xe, nơi bạn gõ code, quản lý dự án và bấm nút chạy.

### 3. Bước 1: Cài Đặt "Động Cơ" — Trình Biên Dịch MinGW

Đây là bước bắt buộc. Nếu bỏ qua, VS Code sẽ báo lỗi không tìm thấy trình biên dịch khi bạn cố chạy code.

**3.1. Tải MinGW**

- Truy cập trang WinLibs.com — đây là nguồn tải MinGW phổ biến, không yêu cầu cài đặt rườm rà, chỉ cần giải nén là dùng được.
- Tại mục Download, chọn phiên bản UCRT runtime (khuyến nghị cho Windows 10/11 hiện đại), định dạng Zip Archive (không cần trình cài đặt), và nên chọn bản Win64 nếu máy bạn dùng Windows 64-bit (đa số máy hiện nay).

**Mẹo:** Nếu không chắc máy mình là 32-bit hay 64-bit, hầu hết máy tính từ năm 2015 trở lại đây đều là 64-bit.

**3.2. Giải Nén Và Đặt Vị Trí Cố Định**

- Sau khi tải xong, giải nén file zip vừa tải. Bạn sẽ thấy một thư mục tên `mingw64`.
- Copy (hoặc cắt) thư mục `mingw64` này và dán vào vị trí cố định, không nên để trong thư mục Downloads hoặc Desktop vì dễ bị xóa nhầm. Ví dụ đường dẫn chuẩn khuyến nghị: `C:\mingw64`

**Lưu ý:** Tránh đặt vào các đường dẫn có dấu cách hoặc ký tự tiếng Việt có dấu, vì có thể gây lỗi khi biên dịch.

**3.3. Khai Báo Đường Dẫn (Add to PATH)**

**PATH** là danh sách các thư mục mà hệ điều hành lần lượt tìm khi bạn gõ một lệnh. Đây là bước quan trọng nhất — nếu làm sai, hệ điều hành sẽ không tìm thấy lệnh `g++`.

- Bấm phím Windows, gõ "env", chọn **Edit the system environment variables**.
- Trong cửa sổ hiện ra, bấm nút **Environment Variables...**
- Ở khung phía dưới (System variables), tìm dòng **Path**, bấm **Edit**.
- Bấm **New**, dán đường dẫn đến thư mục `bin` bên trong MinGW vào. Đường dẫn thường là: `C:\mingw64\bin`
- Bấm **OK** ở tất cả các cửa sổ để lưu lại thay đổi.

**3.4. Kiểm Tra Cài Đặt**

- Mở Command Prompt (CMD).
- Gõ lệnh: `g++ --version`
- Nếu màn hình hiện ra thông tin phiên bản (ví dụ: `g++.exe (MinGW-W64...) 13.x.x`), nghĩa là bạn đã cài đặt "động cơ" thành công!

Nếu hiện lỗi `'g++' is not recognized as an internal or external command`, hãy đóng CMD lại, kiểm tra lại Bước 3.3, sau đó mở CMD **mới** và thử lại (CMD cũ đang mở sẽ không tự cập nhật PATH). Phần mô phỏng ở mục 5 sẽ cho bạn thấy lỗi này xảy ra thế nào.

### 4. Bước 2: Cài Đặt "Vỏ Xe" — VS Code Và Extensions

**4.1. Tải Và Cài Đặt VS Code**

- Truy cập code.visualstudio.com.
- Tải bản cài đặt cho hệ điều hành đang dùng (Windows/macOS/Linux).
- Chạy file cài đặt và làm theo các bước (Next → Next → Finish). Khi cài đặt, nên tích chọn thêm "Add to PATH" và "Add 'Open with Code' action to context menu" (giúp mở nhanh thư mục bằng chuột phải).

**4.2. Cài Đặt Extensions Cần Thiết**

Extension chính là thứ biến VS Code từ một trình soạn thảo văn bản thông thường thành một công cụ lập trình C++ chuyên nghiệp.

- Mở VS Code.
- Bấm vào biểu tượng Extensions (hình 4 ô vuông) ở thanh bên trái, hoặc nhấn tổ hợp phím `Ctrl + Shift + X`.
- Tìm và cài đặt các extension sau:
  - **C/C++ Extension Pack (Microsoft)** — bắt buộc. Cung cấp gợi ý code (IntelliSense), debug, tô màu cú pháp.
  - **Code Runner (Jun Han)** — thêm nút Play ▷ để chạy code nhanh, không cần cấu hình phức tạp.
  - **Better C++ Syntax (Jeff Hykin)** — tùy chọn, tô màu cú pháp C++ chính xác và đẹp hơn.

### 5. Viết Và Chạy Chương Trình Đầu Tiên

VS Code quản lý dự án theo thư mục (Folder), không phải theo từng file rời rạc. Làm đúng theo thứ tự sau để tránh lỗi phát sinh:

**5.1. Tạo Thư Mục Làm Việc**

- Trên máy tính, tạo một thư mục trống, ví dụ: `HocLapTrinhCPP`.
- Trong VS Code, chọn menu **File → Open Folder...**, sau đó chọn thư mục vừa tạo.

**5.2. Tạo File Code**

- Trong khung Explorer bên trái, bấm vào biểu tượng New File (dấu cộng) cạnh tên thư mục.
- Đặt tên file: `hello.cpp` — bắt buộc phải có đuôi `.cpp`, không được là `.c` hay không có đuôi.

**5.3. Viết Code**

Sao chép đoạn code mẫu sau vào file `hello.cpp`:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Xin chao! Toi dang code C++ tren VS Code." << endl;
    return 0;
}
```

Giải thích nhanh:

- `#include <iostream>`: nạp thư viện hỗ trợ nhập/xuất dữ liệu (như `cout`, `cin`).
- `using namespace std;`: cho phép dùng `cout`, `endl`... mà không cần viết đầy đủ `std::cout`.
- `int main() { ... }`: hàm chính, nơi chương trình bắt đầu chạy.
- `cout << "..." << endl;`: in ra màn hình, `endl` dùng để xuống dòng.
- `return 0;`: báo hiệu chương trình kết thúc thành công.

**5.4. Chạy Chương Trình**

**Cách 1 — Dùng Code Runner (đơn giản, phù hợp người mới):**

- Nhìn lên góc trên bên phải màn hình soạn thảo, tìm nút hình tam giác (Play) ▷.
- Bấm vào đó.
- Kết quả sẽ hiện ra ở khung Terminal dưới đáy màn hình: `Xin chao! Toi dang code C++ tren VS Code.`

**Cách 2 — Dùng Terminal thủ công (giúp hiểu rõ quy trình biên dịch):**

- Mở Terminal trong VS Code: menu **Terminal → New Terminal**.
- Gõ lệnh biên dịch: `g++ hello.cpp -o hello`
- Chạy chương trình vừa biên dịch: `.\hello` (trên macOS/Linux là `./hello`)

Cách 2 tuy mất thêm vài giây gõ lệnh nhưng giúp bạn hiểu rõ quy trình thật sự đằng sau nút Play ▷: source code (`.cpp`) → biên dịch (compile) → file thực thi (`.exe`) → chạy chương trình.

#### Xem lệnh g++ làm gì và vì sao thiếu PATH thì báo lỗi

Mô phỏng dưới đây chạy lại Cách 2 trong một Terminal giả lập. Bấm **Bước tiếp** và để ý những điều mà khi cài thật bạn khó thấy:

- Tab **Biên dịch và chạy hello.cpp**: khối nào đang làm việc sáng lên ở dây chuyền phía trên, và tệp `hello.exe` chỉ xuất hiện trong thư mục sau khi `g++` chạy xong. Lệnh `g++` im lặng khi thành công.
- Tab **Lỗi PATH: thiếu C:\mingw64\bin**: Windows tìm `g++.exe` lần lượt trong từng thư mục của PATH (✗ là không có, ✓ là có). Sau khi thêm `C:\mingw64\bin`, Terminal cũ vẫn lỗi; phải mở Terminal mới thì máy mới tìm thấy.

### 6. Xử Lý Các Lỗi Thường Gặp

- `'g++' is not recognized...` → Chưa cài MinGW, hoặc đã cài nhưng chưa thêm vào PATH. Làm lại Bước 3.3, nhớ trỏ đúng vào thư mục `bin`, sau đó mở lại CMD/VS Code.
- `iostream: No such file or directory` → VS Code chưa nhận diện được compiler, hoặc sai đuôi file. Đảm bảo file có đuôi `.cpp`, khởi động lại VS Code.
- Không thấy nút Play ▷ → Chưa cài extension Code Runner. Vào Extensions, cài lại "Code Runner".
- Chương trình chạy ra ký tự tiếng Việt bị lỗi → Terminal Windows mặc định không hiển thị tốt tiếng Việt có dấu. Tạm thời viết chữ không dấu (như ví dụ trong bài) hoặc thêm dòng `system("chcp 65001");` ở đầu hàm `main()` (cần `#include <cstdlib>`).
- `Permission denied` khi chạy file `.exe` → Phần mềm diệt virus chặn file thực thi mới tạo. Thêm thư mục dự án vào danh sách ngoại lệ của phần mềm diệt virus.
- VS Code báo đỏ dưới `#include <iostream>` dù code vẫn chạy được → IntelliSense chưa nhận đúng đường dẫn compiler. Nhấn `Ctrl + Shift + P`, gõ "C/C++: Edit Configurations (UI)", kiểm tra lại Compiler path trỏ đến `C:\mingw64\bin\g++.exe`.

### 7. Một Số Thực Hành Tốt

- Đặt tên file/thư mục không dấu, không khoảng trắng để tránh lỗi biên dịch khó hiểu.
- Mỗi dự án một thư mục riêng, tránh để hàng chục file `.cpp` lẫn lộn.
- Lưu file trước khi chạy (`Ctrl + S`) — Code Runner sẽ chạy đúng phiên bản đã lưu.
- Thỉnh thoảng dùng Terminal thay vì chỉ bấm Play ▷ để hiểu sâu hơn về quá trình biên dịch.
- Tắt/bật lại VS Code khi gặp lỗi lạ — nhiều lỗi liên quan đến IntelliSense hoặc PATH sẽ tự hết sau khi khởi động lại.

### 8. Tổng Kết

Với mô hình VS Code + MinGW, quy trình lập trình C++ của bạn sẽ rất gọn nhẹ và chuyên nghiệp: mở VS Code, **File → Open Folder** chọn thư mục chứa code, viết code trong file `.cpp`, rồi bấm nút Play ▷ (hoặc dùng lệnh `g++` qua Terminal) để biên dịch và chạy.

Đến đây, bạn đã hoàn tất việc thiết lập một môi trường lập trình C++ hiện đại, nhẹ nhàng và đủ mạnh để phục vụ việc học tập cũng như các dự án lập trình sau này.
