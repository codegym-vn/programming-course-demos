Từ git push đến production: dây chuyền CI/CD

Khung bài học này không cho phóng to. Hãy dùng liên kết "Mở bài tương tác toàn màn hình" đặt ngay trong bài.

Mỗi bước trên dây chuyền đều do một đoạn trong tệp YAML quy định. Chọn tình huống rồi bấm Bước tiếp.

.github/workflows/ci-cd.yml

Dây chuyền tự động

git push lên main
CI: tích hợp liên tục
Lấy mã và build
Chạy kiểm thử
CD: triển khai liên tục
Đóng gói Docker
Chờ người duyệt
Lên production
