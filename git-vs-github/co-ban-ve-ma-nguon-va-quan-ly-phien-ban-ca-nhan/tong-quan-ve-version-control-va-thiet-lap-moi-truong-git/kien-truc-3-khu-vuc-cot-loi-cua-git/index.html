Ba khu vực của Git: dữ liệu di chuyển như thế nào?

Khung bài học này không cho phóng to. Hãy dùng liên kết "Mở bài tương tác toàn màn hình" đặt ngay trong bài.

Chọn một tình huống rồi bấm Bước tiếp để chạy từng lệnh, quan sát tệp app.py đi qua Working Directory, Staging Area và Repository.

Các lệnh sẽ chạy

Terminal

① Working Directory

Thư mục làm việc: nơi bạn mở và sửa tệp

app.py

② Staging Area (Index)

Vùng tạm: bản nháp cho commit tiếp theo

app.py

③ Repository (.git)

Kho lưu lịch sử commit; HEAD là commit hiện tại

app.py trong commit HEAD

Dòng có ở Working Directory nhưng chưa addDòng đã add vào Staging Area nhưng chưa commit
