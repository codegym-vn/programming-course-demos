Đọc trạng thái dự án với git status và git diff

Khung bài học này không cho phóng to. Hãy dùng liên kết "Mở bài tương tác toàn màn hình" đặt ngay trong bài.

Bấm Bước tiếp để chạy từng lệnh. Quan sát phiên bản của mỗi tệp trong ba khu vực và cách Git báo cáo sự khác nhau.

Phiên bản của từng tệp

Tệp HEADcommit gần nhất X Staging Area(Index) Y Working Directorythư mục làm việc Trạng thái

X: so Staging Area với HEAD (cột trái của git status -s). Y: so Working Directory với Staging Area (cột phải). Dấu chấm mờ nghĩa là hai bên giống nhau. Rê chuột lên ô v1, v2… để xem nội dung tệp.
