Máy bạn ↔ GitHub: fetch, pull và push

Khung bài học này không cho phóng to. Hãy dùng liên kết "Mở bài tương tác toàn màn hình" đặt ngay trong bài.

Chọn một tab rồi bấm Bước tiếp. Quan sát commit di chuyển giữa kho chứa từ xa và máy của bạn, và con trỏ nào thay đổi sau mỗi lệnh.

    Con trỏ nhánh từ xa (origin/…): chỉ đọc, Git tự cập nhật khi có kết nối mạng.
