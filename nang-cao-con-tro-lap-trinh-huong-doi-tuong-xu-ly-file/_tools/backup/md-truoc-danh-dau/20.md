# 3 Lớp Cơ Bản: ofstream (Ghi), ifstream (Đọc) và fstream

## 1. Mục Tiêu Bài Học

- Hiểu bản chất và nắm vững ba lớp cơ bản để làm việc với file trong C++: `ofstream` (chuyên ghi), `ifstream` (chuyên đọc), và `fstream` (vừa đọc vừa ghi).
- Nắm vững cú pháp: cách khai báo một đối tượng của từng lớp, và việc cần thêm thư viện `#include <fstream>`.
- Hiểu được quy ước đặt tên dễ nhớ: chữ `o` là viết tắt của **Output** (ghi ra), chữ `i` là viết tắt của **Input** (đọc vào).
- Tránh được lỗi phổ biến: dùng nhầm lớp không phù hợp với mục đích, dẫn đến lỗi biên dịch ngay lập tức.

## 2. Giới Thiệu

Ở bài trước, bạn đã thấy sơ lược `ofstream` và `ifstream` xuất hiện trong các ví dụ đầu tiên về ghi và đọc file. Bài này sẽ giới thiệu chính thức và đầy đủ về ba "công cụ" cốt lõi mà C++ cung cấp để làm việc với file — mỗi lớp được thiết kế chuyên biệt cho một mục đích riêng, và việc hiểu rõ sự khác biệt giữa chúng sẽ giúp bạn chọn đúng công cụ ngay từ đầu, tránh được nhiều lỗi không đáng có.

Hãy hình dung ba lớp này giống như ba loại "bút" khác nhau: một loại chỉ dùng để **viết** lên giấy (`ofstream`), một loại chỉ dùng để **đọc** những gì đã viết (`ifstream`), và một loại đa năng hơn có thể làm được cả hai (`fstream`) — tùy vào việc bạn "cầm" nó ở chế độ nào.

## 3. Khái Niệm

- **`ofstream` (Output File Stream)**: lớp chuyên dùng để **ghi** dữ liệu ra file — hỗ trợ toán tử `<<` giống `cout`, nhưng đích đến là file thay vì màn hình.
- **`ifstream` (Input File Stream)**: lớp chuyên dùng để **đọc** dữ liệu từ file — hỗ trợ toán tử `>>` và `getline()` giống `cin`, nhưng nguồn dữ liệu là file thay vì bàn phím.
- **`fstream` (File Stream)**: lớp đa năng, có thể **vừa đọc vừa ghi** trên cùng một đối tượng, tùy vào chế độ (mode) được chỉ định khi mở file.

## 4. Giải Thích

### 4.1. Cú Pháp Sử Dụng ofstream Để Ghi

```cpp
#include <fstream>

ofstream fileGhi("thongtin.txt");
fileGhi << "Nguyen Van An" << endl;   // Dùng << giống cout, nhưng ghi vào FILE
fileGhi.close();
```

Lưu ý: `ofstream` mặc định **tạo file mới**, và nếu file đã có thì **xóa sạch nội dung cũ** trước khi ghi.

### 4.2. Cú Pháp Sử Dụng ifstream Để Đọc

```cpp
ifstream fileDoc("thongtin.txt");
string ten;
getline(fileDoc, ten);   // Dùng getline()/>> giống cin, nhưng đọc từ FILE
fileDoc.close();
```

### 4.3. Cú Pháp Sử Dụng fstream — Đa Năng Hơn

```cpp
fstream file("songoc.txt", ios::out);   // Mở ở chế độ GHI trước
file << "Du lieu ban dau" << endl;
file.close();

file.open("songoc.txt", ios::in);   // Mở LẠI cùng đối tượng, lần này ở chế độ ĐỌC
string noiDung;
getline(file, noiDung);
```

Với `fstream`, bạn cần chỉ định rõ **chế độ** (`ios::out` để ghi, `ios::in` để đọc) — chi tiết về các chế độ này sẽ được học kỹ ở bài sau.

## 5. Ví Dụ

Các output và thông báo lỗi dưới đây lấy từ lần biên dịch, chạy thử thực tế (thông báo lỗi ghi theo g++; trình biên dịch khác có thể diễn đạt khác đi). Ví dụ 1 đến 3 là chương trình đầy đủ, chạy theo thứ tự trong cùng một thư mục.

### Ví dụ 1: ofstream — ghi dữ liệu ra file (Mục tiêu: nắm cú pháp cơ bản của lớp ghi)

```cpp
#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ofstream fileGhi("thongtin.txt");
    fileGhi << "Nguyen Van An" << endl;
    fileGhi << 16 << endl;
    fileGhi.close();

    cout << "Da ghi xong du lieu vao file." << endl;
    return 0;
}
```

**Output:**

```
Da ghi xong du lieu vao file.
```

**Nội dung file `thongtin.txt` sau khi chạy:**

```
Nguyen Van An
16
```

### Ví dụ 2: ifstream — đọc dữ liệu từ file (Mục tiêu: nắm cú pháp cơ bản của lớp đọc)

```cpp
#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main() {
    ifstream fileDoc("thongtin.txt");
    string ten;
    int tuoi;
    getline(fileDoc, ten);
    fileDoc >> tuoi;
    fileDoc.close();

    cout << "Doc duoc: Ten = " << ten << ", Tuoi = " << tuoi << endl;
    return 0;
}
```

**Output:**

```
Doc duoc: Ten = Nguyen Van An, Tuoi = 16
```

`ifstream` đọc lại chính xác dữ liệu đã được `ofstream` ghi ra ở Ví dụ 1 — hai lớp này thường được dùng theo cặp: ghi bằng `ofstream`, sau đó đọc lại bằng `ifstream`. Ở đây `getline` đứng trước `>>` nên không gặp rắc rối với ký tự xuống dòng còn sót; nếu đảo thứ tự (đọc số bằng `>>` rồi mới `getline`), bạn cần bỏ ký tự `'\n'` còn lại bằng `ignore()`.

### Ví dụ 3: fstream — vừa ghi vừa đọc trong cùng một đối tượng (Mục tiêu: hiểu tính đa năng của fstream)

```cpp
#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main() {
    fstream file("songoc.txt", ios::out);
    file << "Du lieu ban dau" << endl;
    file.close();

    file.open("songoc.txt", ios::in);
    string noiDung;
    getline(file, noiDung);
    file.close();

    cout << "Da doc lai: " << noiDung << endl;
    return 0;
}
```

**Output:**

```
Da doc lai: Du lieu ban dau
```

Cùng một đối tượng `file` được dùng để ghi trước (mở ở chế độ `ios::out`), rồi sau đó mở lại ở chế độ `ios::in` để đọc — đây là điểm khác biệt so với `ofstream`/`ifstream` (mỗi lớp chỉ làm được một việc).

### Ví dụ 4: Lỗi — cố ghi bằng ifstream (Mục tiêu: hiểu rõ giới hạn chuyên biệt của từng lớp)

```cpp
ifstream fileDoc("thongtin.txt");
fileDoc << "Thu ghi vao ifstream";   // Cố dùng << để ghi
```

**Thông báo lỗi biên dịch (g++):**

```
error: no match for 'operator<<' (operand types are 'std::ifstream' and 'const char [21]')
```

`ifstream` **không hề định nghĩa** toán tử `<<` — nó chỉ được thiết kế để đọc, không thể dùng để ghi dù chỉ một ký tự.

### Ví dụ 5: Lỗi — cố đọc bằng ofstream (Mục tiêu: xác nhận giới hạn ngược lại)

```cpp
ofstream fileGhi("thongtin.txt");
int x;
fileGhi >> x;   // Cố dùng >> để đọc
```

**Thông báo lỗi biên dịch (g++):**

```
error: no match for 'operator>>' (operand types are 'std::ofstream' and 'int')
```

Tương tự, `ofstream` **không hề định nghĩa** toán tử `>>` — nó chỉ được thiết kế để ghi, không thể dùng để đọc.

Mô phỏng dưới đây vẽ mỗi lớp thành một **ống** nối chương trình với tệp. Bấm **Bước tiếp** để chạy từng dòng code và để ý những điều mà chữ khó diễn tả:

- Tab **ifstream: đọc**: dữ liệu chảy ngược lên hộp `ten` và `tuoi` trong chương trình, còn tệp trên đĩa không hề thay đổi.

## 6. Phần Chú Ý Và Lỗi Hay Gặp

- **Dùng sai lớp cho mục đích ngược lại**: dùng `ifstream` để ghi hoặc `ofstream` để đọc sẽ gây lỗi biên dịch ngay lập tức (xem lại Ví dụ 4 và 5) — đây thực chất là một điểm **an toàn** của C++, giúp bạn phát hiện lỗi thiết kế ngay từ khi biên dịch, thay vì để chương trình chạy sai một cách âm thầm.
- **Quên `#include <fstream>`**: cả ba lớp `ofstream`, `ifstream`, `fstream` đều nằm trong thư viện `<fstream>`, khác với `<iostream>` (chứa `cin`, `cout`) đã quen dùng — thiếu dòng include này sẽ gây lỗi biên dịch không nhận diện được các lớp này.
- **Không đóng file sau khi dùng xong (`.close()`)**: dù chương trình vẫn có thể chạy được nếu quên `.close()` trong nhiều trường hợp đơn giản, đây là một thói quen xấu — luôn đóng file sau khi hoàn tất, để đảm bảo dữ liệu được lưu đầy đủ và giải phóng tài nguyên hệ thống đúng cách.
- **Quên rằng `ofstream` xóa nội dung cũ**: mở một file đã có bằng `ofstream` mà không chỉ định chế độ nào khác sẽ xóa sạch nội dung cũ của file đó (cách ghi nối thêm vào cuối file sẽ học ở bài về chế độ mở file).
- **Dùng `fstream` khi chỉ cần `ofstream` hoặc `ifstream` đơn giản**: nếu chương trình của bạn chỉ cần thuần túy ghi hoặc thuần túy đọc, việc dùng `ofstream`/`ifstream` sẽ rõ ràng và an toàn hơn `fstream` — chỉ nên dùng `fstream` khi thực sự cần cả hai chức năng trên cùng một file trong cùng một chương trình.
- **Nhầm lẫn quy ước đặt tên `o` và `i`**: ghi nhớ đơn giản — `o` (Output) là **ghi ra** file, `i` (Input) là **đọc vào** từ file — quy ước này nhất quán với các khái niệm Input/Output đã học từ đầu khóa (như `cin`/`cout`).
