Lớp là khuôn, đối tượng là sản phẩm

Giống một khuôn làm bánh: một khuôn, nhiều chiếc bánh, mỗi chiếc có nhân riêng

Lớp (class): bản thiết kế
HocSinh
string ten
int tuoi

Đối tượng (object): có dữ liệu riêng
