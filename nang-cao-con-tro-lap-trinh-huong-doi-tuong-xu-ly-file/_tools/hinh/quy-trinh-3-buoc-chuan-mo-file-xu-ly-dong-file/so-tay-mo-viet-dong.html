Quy trình 3 bước giống dùng cuốn sổ tay

Mở sổ, viết, rồi gấp sổ lại

BƯỚC 1
Mở
ofstream f("a.txt");
Mở sổ ra
BƯỚC 2
Xử lý
f << "..." ;
Viết vào sổ (chữ nằm trong bộ đệm)
BƯỚC 3
Đóng
f.close();
Gấp sổ: chữ xuống hẳn tệp
Quên bước 3: chữ có thể còn nằm trong bộ đệm, chưa xuống đĩa. Ai mở tệp lúc đó có thể thấy tệp rỗng.
