# Đọc File Theo Từng Dòng Bằng Vòng Lặp (while + getline)

## 1. Mục Tiêu Bài Học

- Hiểu bản chất: vì sao cần dùng vòng lặp để đọc file — vì bạn thường **không biết trước** file có bao nhiêu dòng dữ liệu.
- Nắm vững cú pháp chuẩn: `while (getline(file, dong)) { ... }` — cách hoạt động dựa trên giá trị trả về của `getline()`.
- Tránh được lỗi kinh điển bậc nhất khi đọc file trong C++: dùng `while (!file.eof())` — hiểu rõ vì sao cách này sai và cách nó gây ra lỗi đọc dư dữ liệu.
- Ứng dụng được vào các bài toán thực tế: tìm kiếm từ khóa trong file, đọc và xử lý một dãy số từ file.
- Quan sát hai kiểu vòng lặp chạy song song bằng hoạt động mô phỏng.

## 2. Giới Thiệu

Ở các bài trước, bạn đã đọc file với số dòng **biết trước** — ví dụ đọc đúng 2 dòng bằng hai lệnh `getline()` liên tiếp. Nhưng trong thực tế, file thường có số dòng không xác định trước: có thể là danh sách 5 học sinh, cũng có thể là 5.000 học sinh. Bạn cần một cách để đọc "cho đến khi hết file", bất kể file dài bao nhiêu.

Đây chính là lúc kết hợp vòng lặp `while` với `getline()` phát huy tác dụng. Nhưng đây cũng là nơi ẩn chứa một trong những lỗi phổ biến và "khét tiếng" nhất khi học C++ — nhiều tài liệu, kể cả một số giáo trình, vẫn dạy sai cách kiểm tra "đã hết file chưa", dẫn đến một lỗi âm thầm mà người mới học rất khó tự phát hiện ra.

## 3. Khái Niệm

- **Đọc file theo vòng lặp**: kỹ thuật dùng vòng lặp (`while`) để đọc liên tục từng dòng (hoặc từng phần tử) của file, cho đến khi không còn dữ liệu để đọc.
- **Giá trị trả về của `getline()`**: hàm `getline(file, dong)` không chỉ đọc dữ liệu vào biến `dong`, mà còn trả về chính đối tượng `file` đó — đối tượng này có thể được đánh giá như `true` (đọc thành công) hoặc `false` (đọc thất bại, thường vì đã hết file).
- **`eof()` (End Of File)**: phương thức kiểm tra xem một lần đọc trước đó đã chạm tới điểm cuối file hay chưa — cờ này chỉ được bật **khi một lần đọc đã chạm cuối file**, không phải ngay khi còn một lần đọc nữa là hết.

## 4. Giải Thích

### 4.1. Cú Pháp Đúng: while (getline(file, dong))

```cpp
ifstream f("danhsach.txt");
string dong;
while (getline(f, dong)) {   // Đọc và kiểm tra NGAY LẬP TỨC kết quả của phép đọc đó
    cout << dong << endl;
}
```

Cách hoạt động: mỗi lần lặp, `getline()` cố gắng đọc một dòng mới. Nếu đọc **thành công** (còn dữ liệu), nó trả về giá trị tương đương `true`, vòng lặp tiếp tục. Nếu đọc **thất bại** (đã hết file), nó trả về giá trị tương đương `false`, vòng lặp dừng ngay lập tức — không có dòng "rác" nào lọt vào.

### 4.2. Lỗi Kinh Điển: while (!file.eof())

```cpp
ifstream f("danhsach.txt");
string dong;
while (!f.eof()) {   // SAI!
    getline(f, dong);
    cout << dong << endl;
}
```

Vấn đề nằm ở **thời điểm** cờ `eof()` được bật: nó chỉ bật **sau khi** một lần đọc đã chạm cuối file, chứ không phải "biết trước" dòng sắp đọc là dòng cuối. Với file mà dòng cuối kết thúc bằng ký tự xuống dòng (ví dụ file được ghi bằng `endl`), sau khi đọc xong dòng cuối hợp lệ, `eof()` **vẫn chưa** được bật — vòng lặp chạy thêm một lần nữa, cố đọc một dòng không tồn tại, và dòng "rác" đó vẫn bị xử lý như dữ liệu thật.

## 5. Ví Dụ

Các output dưới đây được lấy từ lần chạy thực tế (biên dịch bằng trình biên dịch C++17), trên một file mẫu `danhsach.txt` gồm đúng 3 dòng (`"Nguyen Van An"`, `"Tran Thi Binh"`, `"Le Van Cuong"`), mỗi dòng kết thúc bằng ký tự xuống dòng.

### Ví dụ 1: Đọc file đúng cách bằng while (getline(...)) (Mục tiêu: nắm cú pháp chuẩn)

```cpp
#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main() {
    ifstream f("danhsach.txt");
    string dong;
    int soDong = 0;

    while (getline(f, dong)) {
        soDong++;
        cout << "Dong " << soDong << ": " << dong << endl;
    }
    f.close();

    cout << "Tong so dong da doc: " << soDong << endl;
    return 0;
}
```

**Output đã kiểm chứng:**

```
Dong 1: Nguyen Van An
Dong 2: Tran Thi Binh
Dong 3: Le Van Cuong
Tong so dong da doc: 3
```

Kết quả chính xác tuyệt đối: đọc đúng 3 dòng, không thừa, không thiếu.

### Ví dụ 2: Lỗi kinh điển — while (!file.eof()) gây đọc dư dòng cuối (Mục tiêu: hiểu rõ và tránh lỗi phổ biến nhất)

```cpp
#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main() {
    ifstream f("danhsach.txt");
    string dong;
    int soDong = 0;

    while (!f.eof()) {
        getline(f, dong);
        soDong++;
        cout << "Dong " << soDong << ": [" << dong << "]" << endl;
    }
    f.close();

    cout << "Tong so dong (SAI, du 1 dong rac!): " << soDong << endl;
    return 0;
}
```

**Output đã kiểm chứng (cùng file 3 dòng, nhưng kết quả sai lệch):**

```
Dong 1: [Nguyen Van An]
Dong 2: [Tran Thi Binh]
Dong 3: [Le Van Cuong]
Dong 4: []
Tong so dong (SAI, du 1 dong rac!): 4
```

Đây là bằng chứng rõ ràng nhất của lỗi: chương trình báo cáo đọc được **4 dòng**, dù file chỉ có 3 dòng thực sự! Dòng thứ 4 là một chuỗi **rỗng** — kết quả của lần `getline()` thất bại nhưng vẫn bị xử lý như một dòng hợp lệ, chỉ vì `eof()` chưa kịp "biết" là đã hết file tại thời điểm kiểm tra điều kiện vòng lặp.

Điều đáng sợ hơn: nếu dòng cuối của file **không** có ký tự xuống dòng, lần `getline` thứ 3 đã chạm cuối file và bật `eof()`, nên chương trình trên lại cho đúng 3 dòng. Lỗi lúc có lúc không như vậy càng khó phát hiện.

### Ví dụ 3: Ứng dụng thực tế — tìm kiếm từ khóa trong file (Mục tiêu: ứng dụng đọc vòng lặp vào bài toán tìm kiếm)

```cpp
#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main() {
    ifstream f("danhsach.txt");
    string dong;
    string tuKhoa = "Van";
    int demTimThay = 0;

    while (getline(f, dong)) {
        if (dong.find(tuKhoa) != string::npos) {
            cout << "Tim thay: " << dong << endl;
            demTimThay++;
        }
    }
    f.close();

    cout << "So dong chua '" << tuKhoa << "': " << demTimThay << endl;
    return 0;
}
```

**Output đã kiểm chứng:**

```
Tim thay: Nguyen Van An
Tim thay: Le Van Cuong
So dong chua 'Van': 2
```

Kỹ thuật đọc vòng lặp kết hợp với `.find()` (đã học ở phần Chuỗi) cho phép quét qua toàn bộ file, tìm ra chính xác những dòng có chứa từ khóa `"Van"` — đúng 2 trong số 3 dòng, bỏ qua dòng `"Tran Thi Binh"` không chứa từ khóa này.

### Ví dụ 4: Đọc một dãy số bằng while (file >> bien) — cùng nguyên tắc, khác cú pháp (Mục tiêu: mở rộng nguyên tắc sang trường hợp đọc số)

```cpp
#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ifstream f("diemso.txt");   // File chua: "8 7 9 6 10"
    int diem;
    int tong = 0, dem = 0;

    while (f >> diem) {   // Cung nguyen tac: kiem tra KET QUA cua phep doc, khong dung eof()
        tong += diem;
        dem++;
        cout << "Doc duoc diem: " << diem << endl;
    }
    f.close();

    cout << "Tong so diem: " << dem << ", Tong diem: " << tong << endl;
    return 0;
}
```

**Output đã kiểm chứng:**

```
Doc duoc diem: 8
Doc duoc diem: 7
Doc duoc diem: 9
Doc duoc diem: 6
Doc duoc diem: 10
Tong so diem: 5, Tong diem: 40
```

Nguyên tắc "kiểm tra kết quả của chính phép đọc" không chỉ áp dụng cho `getline()` — nó áp dụng cho **mọi** thao tác đọc từ file, kể cả dùng toán tử `>>` để đọc số. Kết quả đọc đúng chính xác 5 số, tổng bằng `40`, không có phần tử "rác" nào bị đọc dư.

### Xem hai vòng lặp chạy song song

Bấm **Bước tiếp** để hai vòng lặp cùng đọc một tệp. Mô phỏng cho thấy những điều mà chữ khó diễn tả:

- Tab **getline và !eof()**: ba đèn `good()`, `eof()`, `fail()` của luồng `f` cho thấy ở cột phải, sau dòng 3 đèn `eof()` vẫn tắt, nên vòng lặp bước vào lượt thứ 4; chỉ khi `getline` đọc hụt thì đèn mới bật, nhưng dòng thừa đã bị in.
- Tab **Dòng cuối không có ↵**: cùng hai vòng lặp nhưng tệp không kết thúc bằng xuống dòng, cột phải bất ngờ ra đúng 3, tức là lỗi chỉ xuất hiện tùy tệp.
- Tab **Đọc số: f >> diem**: bảng lượt lặp cho thấy `tong` tăng dần 8, 15, 24, 30, 40 rồi lượt thứ 6 đọc hụt và vòng lặp dừng.

## 6. Phần Chú Ý Và Lỗi Hay Gặp

- **Dùng `while (!file.eof())` để kiểm tra điều kiện đọc file**: đây là lỗi phổ biến và nguy hiểm nhất khi đọc file (xem lại Ví dụ 2) — **tuyệt đối** tránh cách viết này; luôn kiểm tra trực tiếp kết quả của phép đọc (`getline(...)` hoặc `file >> bien`) làm điều kiện vòng lặp.
- **Không nhận ra hậu quả của lỗi `eof()` vì dữ liệu "trông có vẻ ổn"**: với file nhỏ, dòng "rác" thừa ra (thường là chuỗi rỗng hoặc giá trị cũ của biến) có thể không gây crash ngay, khiến lỗi này rất dễ bị bỏ qua — nhưng nó vẫn làm sai lệch kết quả tính toán (như số dòng, tổng số...). Với dữ liệu số, `while (!f.eof())` còn có thể xử lý lặp lại giá trị cuối, hoặc lặp mãi khi gặp dữ liệu sai định dạng.
- **Nhầm lẫn cách xử lý giữa đọc theo dòng (`getline`) và đọc theo giá trị (`>>`)**: dù cú pháp cụ thể khác nhau đôi chút, nguyên tắc kiểm tra kết quả đọc trực tiếp trong điều kiện vòng lặp là như nhau cho cả hai (xem lại Ví dụ 1 và 4).
- **Không kiểm tra file có mở thành công hay không trước khi bắt đầu vòng lặp đọc**: nếu file không tồn tại hoặc mở thất bại, vòng lặp `while (getline(...))` sẽ tự động dừng ngay từ lần lặp đầu tiên (vì phép đọc thất bại ngay) — nhưng để chương trình xử lý rõ ràng hơn (thông báo lỗi cụ thể), nên chủ động kiểm tra `is_open()` trước, như đã học ở Bài 4.3.
- **Không tận dụng được sức mạnh của vòng lặp đọc file khi xử lý dữ liệu lớn**: chính kỹ thuật này (không phải đọc từng dòng cố định như bài trước) mới là công cụ thực sự dùng được trong các chương trình xử lý file thực tế — nơi số lượng dòng dữ liệu là không biết trước và có thể thay đổi theo thời gian.
