Khai báo và định nghĩa: khác nhau ở đâu?

Cùng một hàm tinhTong, viết theo hai kiểu

Khai báo (prototype)
"Có một hàm như thế này"
int tinhTong(int a, int b);
  • Kết thúc bằng dấu ;
  • Không có thân hàm
  • Chỉ cần kiểu tham số, tên có thể bỏ
Định nghĩa (definition)
"Đây là cách hàm làm việc"
int tinhTong(int a, int b) { return a + b; }
  • Có thân hàm trong { }
  • Mỗi hàm chỉ định nghĩa một lần
  • Cũng đã tính là khai báo
Gọi hàm được khi trình biên dịch đã thấy một trong hai ở phía trên chỗ gọi.
