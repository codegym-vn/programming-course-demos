Một hàm gồm bốn phần

Đọc từ trái sang phải: "hàm tên tinhTong, nhận hai số int, trả về một số int"

int tinhTong(int a, int b) { return a + b; }
intKiểu trả về. Không trả gì thì ghi void
tinhTongTên hàm, đặt như tên biến
(int a, int b)Tham số: đầu vào hàm cần, có thể để trống
{ ... }Thân hàm: nơi xử lý và return
Gọi hàm: tinhTong(5, 3); chỉ cần tên hàm và các giá trị đưa vào, không viết lại kiểu.
