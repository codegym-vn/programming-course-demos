# Thao tác nhập - xuất mảng trong C++

## 1. Mục Tiêu Bài Học

- Hiểu bản chất: vì sao cần kết hợp vòng lặp `for` để nhập và xuất toàn bộ mảng, thay vì viết tay từng dòng `cin`/`cout` riêng lẻ.
- Nắm vững cú pháp: cách kết hợp `for` với `cin >>` để nhập dữ liệu vào mảng, và với `cout <<` để xuất dữ liệu ra màn hình.
- Ứng dụng được vào các chương trình thực tế: nhập điểm học sinh, xuất danh sách theo nhiều định dạng khác nhau.
- Tránh được lỗi off-by-one (sai lệch 1 đơn vị) — nguyên nhân phổ biến nhất gây ra lỗi truy cập ngoài phạm vi khi nhập/xuất mảng.

## 2. Giới Thiệu

Ở bài trước, bạn đã biết cách khai báo mảng và gán giá trị cho từng phần tử bằng cách viết tay: `diem[0] = 8; diem[1] = 9;`... Nhưng cách viết tay này chỉ chấp nhận được với mảng vài phần tử — nếu mảng có 100 hay 1000 phần tử, bạn không thể ngồi gõ tay từng dòng `cin >> diem[i]` cho mỗi chỉ số.

Giải pháp là kết hợp vòng lặp `for` (đã học ở các bài trước) với `cin` và `cout`: vì chỉ số mảng là những con số liên tiếp (0, 1, 2, 3...), và biến đếm `i` trong `for` cũng chạy qua các con số liên tiếp y hệt như vậy — hai thứ này khớp với nhau một cách hoàn hảo. Đây chính là kỹ thuật nền tảng nhất, sẽ được dùng lại xuyên suốt trong hầu hết các bài toán về mảng sau này.

## 3. Khái Niệm

- **Nhập mảng**: quá trình đưa dữ liệu từ bàn phím (`cin`) vào từng phần tử của mảng, thường thực hiện bằng vòng lặp `for` chạy qua từng chỉ số.
- **Xuất mảng**: quá trình hiển thị giá trị của từng phần tử trong mảng ra màn hình (`cout`), cũng thường dùng vòng lặp `for` tương tự.
- **Lỗi off-by-one (sai lệch 1 đơn vị)**: lỗi phổ biến khi vòng lặp chạy dư hoặc thiếu đúng 1 lần so với số phần tử thực tế của mảng — thường do dùng sai dấu so sánh (`<=` thay vì `<`) trong điều kiện của `for`.

## 4. Giải Thích

### 4.1. Công Thức Chung Để Nhập Mảng

```
for (int i = 0; i < n; i++) {
    cin >> tên_mảng[i];
}
```

Vòng lặp chạy từ `i = 0` đến `i = n - 1` (đúng `n` lần), mỗi lần nhập một giá trị từ bàn phím vào đúng vị trí `tên_mảng[i]`.

### 4.2. Công Thức Chung Để Xuất Mảng

```
for (int i = 0; i < n; i++) {
    cout << tên_mảng[i] << " ";
}
```

Tương tự như nhập, nhưng đổi chiều: lấy giá trị từ `tên_mảng[i]` và in ra màn hình.

### 4.3. Điểm Mấu Chốt Cần Ghi Nhớ

Điều kiện của vòng lặp phải luôn là `i < n` (nhỏ hơn), **không phải** `i <= n` (nhỏ hơn hoặc bằng) — vì với mảng có `n` phần tử, chỉ số hợp lệ cuối cùng chỉ là `n - 1`. Dùng nhầm `<=` sẽ khiến vòng lặp chạy dư đúng 1 lần, cố gắng truy cập vào một chỉ số không tồn tại — chi tiết minh chứng cụ thể ở Ví dụ 5.

## 5. Ví Dụ

Các chương trình dưới đây đã được biên dịch và chạy thử thực tế. Ở phần output, **các số và chữ do người dùng gõ vào** được ghi ngay sau dòng nhắc, đúng như bạn sẽ thấy trên màn hình (mỗi lần gõ xong bấm Enter nên xuống dòng).

### Ví dụ 1: Nhập và xuất mảng số nguyên cơ bản (Mục tiêu: nắm cú pháp cơ bản)

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 5;
    int diem[5];

    cout << "Nhap diem cho " << n << " hoc sinh:" << endl;
    for (int i = 0; i < n; i++) {
        cout << "Diem hoc sinh thu " << (i + 1) << ": ";
        cin >> diem[i];
    }

    cout << "Danh sach diem vua nhap: ";
    for (int i = 0; i < n; i++) {
        cout << diem[i] << " ";
    }
    cout << endl;
    return 0;
}
```

**Output khi lần lượt nhập `8`, `9`, `7`, `10`, `6`:**

```
Nhap diem cho 5 hoc sinh:
Diem hoc sinh thu 1: 8
Diem hoc sinh thu 2: 9
Diem hoc sinh thu 3: 7
Diem hoc sinh thu 4: 10
Diem hoc sinh thu 5: 6
Danh sach diem vua nhap: 8 9 7 10 6 
```

Lưu ý: hai vòng lặp `for` ở đây hoàn toàn tách biệt — vòng đầu dùng để nhập, vòng sau dùng để xuất — dù cả hai đều dùng chung biến đếm `i` chạy từ `0` đến `n-1`.

### Ví dụ 2: Nhập số lượng động và xuất bảng điểm có định dạng (Mục tiêu: ứng dụng thực tế)

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "Nhap so luong hoc sinh: ";
    cin >> n;

    int diem[100];   // Mảng đủ lớn để chứa tối đa 100 học sinh
    for (int i = 0; i < n; i++) {
        cout << "Nhap diem hoc sinh thu " << (i + 1) << ": ";
        cin >> diem[i];
    }

    cout << "\n--- BANG DIEM ---" << endl;
    for (int i = 0; i < n; i++) {
        cout << "Hoc sinh " << (i + 1) << ": " << diem[i] << " diem" << endl;
    }
    return 0;
}
```

**Output khi nhập `n = 3` và điểm `7`, `8`, `9`:**

```
Nhap so luong hoc sinh: 3
Nhap diem hoc sinh thu 1: 7
Nhap diem hoc sinh thu 2: 8
Nhap diem hoc sinh thu 3: 9

--- BANG DIEM ---
Hoc sinh 1: 7 diem
Hoc sinh 2: 8 diem
Hoc sinh 3: 9 diem
```

Đây là kỹ thuật rất thực tế: thay vì cố định số lượng phần tử ngay từ đầu, ta khai báo mảng với kích thước "đủ lớn" (`diem[100]`), rồi để biến `n` (nhập từ người dùng) quyết định thực sự sẽ dùng bao nhiêu phần tử trong số đó. Nhớ rằng `n` không được vượt quá `100`.

### Ví dụ 3: Nhập và xuất mảng kiểu chuỗi (string) (Mục tiêu: ứng dụng với kiểu dữ liệu khác)

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int n = 3;
    string ten[3];

    for (int i = 0; i < n; i++) {
        cout << "Ten hoc sinh " << (i + 1) << ": ";
        cin >> ten[i];
    }

    cout << "\nDanh sach ten:" << endl;
    for (int i = 0; i < n; i++) {
        cout << "- " << ten[i] << endl;
    }
    return 0;
}
```

**Output khi nhập `An`, `Binh`, `Chi`:**

```
Ten hoc sinh 1: An
Ten hoc sinh 2: Binh
Ten hoc sinh 3: Chi

Danh sach ten:
- An
- Binh
- Chi
```

Công thức nhập/xuất bằng `for` hoàn toàn không đổi dù mảng chứa kiểu dữ liệu nào — số nguyên, số thực, hay chuỗi ký tự đều dùng chung một cấu trúc vòng lặp giống hệt nhau.

### Ví dụ 4: Xuất mảng theo định dạng liệt kê, cách nhau bằng dấu phẩy (Mục tiêu: ứng dụng, đa dạng cách trình bày)

```cpp
#include <iostream>
using namespace std;

int main() {
    int soLuong[4] = {12, 45, 7, 30};
    int n = 4;

    cout << "Danh sach: ";
    for (int i = 0; i < n; i++) {
        cout << soLuong[i];
        if (i < n - 1) {
            cout << ", ";     // Chỉ in dấu phẩy nếu CHƯA phải phần tử cuối
        }
    }
    cout << endl;
    return 0;
}
```

**Output đã kiểm chứng:**

```
Danh sach: 12, 45, 7, 30
```

Chú ý điều kiện `if (i < n - 1)`: nó đảm bảo dấu phẩy chỉ xuất hiện **giữa** các phần tử, không bị dư một dấu phẩy thừa ở cuối cùng (tránh kết quả xấu như `12, 45, 7, 30,`). Đây là một mẹo định dạng nhỏ nhưng rất hay dùng trong thực tế.

### Ví dụ 5: Lỗi off-by-one — dùng sai <= thay vì < (Mục tiêu: tránh lỗi)

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 5;
    int diem[5];

    // Lỗi: dùng <= n thay vì < n, sẽ chạy từ i=0 đến i=5 (6 lần thay vì 5 lần)
    for (int i = 0; i <= n; i++) {
        cout << "Dang nhap diem[" << i << "]: ";
        cin >> diem[i];
    }
    return 0;
}
```

**Output khi nhập đủ 6 giá trị (`1`, `2`, `3`, `4`, `5`, `6`):**

```
Dang nhap diem[0]: 1
Dang nhap diem[1]: 2
Dang nhap diem[2]: 3
Dang nhap diem[3]: 4
Dang nhap diem[4]: 5
Dang nhap diem[5]: 6
```

Điều đáng lo ngại: chương trình vẫn biên dịch được và vẫn xin nhập tới `diem[5]`, một vị trí **không tồn tại** trong mảng chỉ có 5 phần tử (chỉ số hợp lệ là 0 đến 4). Số `6` bị ghi vào một vùng nhớ không thuộc mảng — đây là **hành vi không xác định**: nó có thể ghi đè lên biến khác (kể cả chính biến `i` hay `n`, khiến vòng lặp chạy lung tung) hoặc làm chương trình bị dừng đột ngột. Trong một lần chạy thử, chương trình đã in hết các dòng trên rồi bị hệ thống dừng khi kết thúc; trên máy khác có thể không thấy dấu hiệu nào. Đây chính là hệ quả trực tiếp của lỗi out-of-bounds đã học ở bài trước, nhưng lần này xảy ra ngay trong bước **nhập liệu** — một trong những nơi dễ mắc lỗi off-by-one nhất.

## 6. Phần Chú Ý Và Lỗi Hay Gặp

- **Dùng `<=` thay vì `<` trong điều kiện vòng lặp**: đây là lỗi off-by-one phổ biến nhất khi nhập/xuất mảng (xem lại Ví dụ 5) — luôn nhớ quy tắc "mảng `n` phần tử thì lặp `i` từ `0` đến `n-1`, dùng `i < n`".
- **Quên đồng bộ giữa kích thước mảng khai báo và số lần lặp thực tế**: nếu khai báo `int arr[100]` nhưng chỉ dùng `n = 5` phần tử thực sự, phải luôn dùng biến `n` (không phải con số `100`) làm điều kiện dừng của vòng lặp — nếu không, chương trình sẽ cố xử lý cả những phần tử chưa từng được gán giá trị.
- **Nhầm lẫn vòng lặp nhập và vòng lặp xuất là một**: dù cùng cấu trúc `for (int i = 0; i < n; i++)`, đây luôn là **hai vòng lặp riêng biệt** — một vòng chuyên nhập dữ liệu (`cin >>`), một vòng chuyên xuất dữ liệu (`cout <<`), không thể gộp chung làm một nếu bạn cần nhập xong toàn bộ trước rồi mới xuất toàn bộ.
- **Không kiểm tra kiểu dữ liệu khớp giữa mảng và giá trị nhập vào**: nếu khai báo mảng kiểu `int` nhưng người dùng lỡ nhập một giá trị có phần thập phân (ví dụ `8.5`), `cin` sẽ chỉ đọc được phần nguyên (`8`) và để lại phần dư (`.5`) trong bộ nhớ đệm; lần đọc tiếp theo gặp `.5` sẽ thất bại, `cin` rơi vào trạng thái lỗi và các phần tử sau không được nhập nữa. Cần cẩn trọng khi thiết kế chương trình nhận dữ liệu từ người dùng thực tế.
- **In dư ký tự phân cách ở cuối danh sách**: khi xuất mảng theo định dạng có dấu phân cách (dấu phẩy, gạch ngang...), luôn nhớ thêm điều kiện kiểm tra "chưa phải phần tử cuối" (như Ví dụ 4) để tránh để lại một dấu phân cách thừa không cần thiết ở cuối kết quả.
