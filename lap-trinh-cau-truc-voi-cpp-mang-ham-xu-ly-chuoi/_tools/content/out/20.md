# Các Hàm Xử Lý Chuỗi Thông Dụng

## 1. Mục Tiêu Bài Học

- Hiểu bản chất: `std::string` đi kèm sẵn rất nhiều hàm thành viên (member function) hữu ích, giúp xử lý chuỗi mà không cần tự viết logic từ đầu.
- Nắm vững cách dùng `.length()` / `.size()` để lấy độ dài chuỗi, và `.substr()` để cắt lấy một đoạn chuỗi con.
- Nắm vững cách dùng `.find()` để tìm vị trí xuất hiện của một ký tự hoặc chuỗi con, cùng hằng số đặc biệt `string::npos` để xử lý trường hợp không tìm thấy.
- Ứng dụng được vào các bài toán thực tế: tách họ và tên riêng, kiểm tra định dạng email cơ bản.

## 2. Giới Thiệu

Ở bài trước, bạn đã biết cách khai báo, khởi tạo và thực hiện các phép toán cơ bản (nối, so sánh) trên `std::string`. Nhưng sức mạnh thực sự của `std::string` nằm ở một kho các **hàm thành viên** đi kèm sẵn — những công cụ giúp bạn xử lý chuỗi một cách nhanh chóng mà không cần tự viết vòng lặp để làm những việc như đếm ký tự hay cắt chuỗi con.

Hãy tưởng tượng bạn cần kiểm tra xem một địa chỉ email có chứa ký tự `@` hay không, hoặc cần tách riêng họ và tên từ một chuỗi họ tên đầy đủ — nếu không có các hàm dựng sẵn này, bạn sẽ phải tự viết vòng lặp duyệt qua từng ký tự để làm những việc tưởng chừng đơn giản này. Trong bài này, bạn sẽ làm quen với bốn hàm xử lý chuỗi thông dụng nhất, giúp giải quyết những bài toán như vậy chỉ trong một dòng lệnh.

## 3. Khái Niệm

- `.length()` / `.size()`: hai hàm hoàn toàn tương đương nhau, trả về số lượng ký tự hiện có trong chuỗi.
- `.substr(vị_trí_bắt_đầu, số_ký_tự)`: hàm cắt ra một đoạn chuỗi con, bắt đầu từ một vị trí (chỉ số) cho trước, với độ dài tùy chọn.
- `.find(giá_trị_cần_tìm)`: hàm tìm kiếm vị trí xuất hiện **đầu tiên** của một ký tự hoặc chuỗi con bên trong chuỗi gốc.
- `string::npos`: một hằng số đặc biệt, được `.find()` trả về khi **không tìm thấy** giá trị cần tìm — dùng để kiểm tra kết quả tìm kiếm có thành công hay không.
- `.append(chuỗi_cần_nối)`: hàm nối thêm nội dung vào cuối chuỗi hiện tại, có công dụng tương tự toán tử `+=` đã học ở bài trước.

## 4. Giải Thích

### 4.1. Lấy Độ Dài Chuỗi

```cpp
string ten = "Nguyen Van A";
int doDai = ten.length();   // hoặc ten.size() - hoàn toàn tương đương
```

### 4.2. Cắt Chuỗi Con Với .substr()

```cpp
string tenChuoi = "Hello World";
string doanCon = tenChuoi.substr(6, 5);   // Cú pháp: substr(viTriBatDau, soKyTu) -> "World"
```

### 4.3. Tìm Kiếm Với .find() Và Xử Lý Khi Không Tìm Thấy

```cpp
string tenChuoi = "hocvien@gmail.com";
size_t viTri = tenChuoi.find('@');   // Cú pháp: find(giaTriCanTim)
if (viTri == string::npos) {
    // Không tìm thấy
} else {
    // Tìm thấy tại vị trí viTri
}
```

Lưu ý kiểu dữ liệu trả về là `size_t` (một dạng số nguyên không dấu), không phải `int` thông thường — khi không tìm thấy, `.find()` trả về `string::npos`, một giá trị đặc biệt (thực chất là con số rất lớn) chứ **không phải** `-1` như nhiều ngôn ngữ khác. Vì vậy hãy luôn so sánh với `string::npos`. (Viết `viTri == -1` tình cờ vẫn chạy đúng khi `viTri` là `size_t`, vì `-1` bị đổi thành số lớn nhất của `size_t`; nhưng nếu lỡ gán kết quả vào biến `int` thì rất dễ sai, và trình biên dịch sẽ cảnh báo so sánh số có dấu với số không dấu.)

## 5. Ví Dụ

Toàn bộ output dưới đây đã được biên dịch và chạy thử thực tế để kiểm chứng. Giá trị `18446744073709551615` ở Ví dụ 3 là của máy 64-bit.

### Ví dụ 1: Lấy độ dài chuỗi bằng .length() và .size() (Mục tiêu: nắm hàm cơ bản nhất)

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string ten = "Nguyen Van A";
    cout << "Do dai (length): " << ten.length() << endl;
    cout << "Do dai (size): " << ten.size() << endl;

    string rong = "";
    cout << "Do dai chuoi rong: " << rong.length() << endl;
    return 0;
}
```

**Output đã kiểm chứng:**

```
Do dai (length): 12
Do dai (size): 12
Do dai chuoi rong: 0
```

`"Nguyen Van A"` có đúng 12 ký tự (tính cả 2 khoảng trắng), và `.length()` với `.size()` luôn cho ra kết quả giống hệt nhau — bạn có thể dùng tùy ý cái nào cũng được.

### Ví dụ 2: Cắt chuỗi con bằng .substr() (Mục tiêu: nắm cách tách một phần của chuỗi)

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string ngayStr = "15/07/2026";

    string ngay = ngayStr.substr(0, 2);        // Từ chỉ số 0, lấy 2 ký tự
    string thang = ngayStr.substr(3, 2);       // Từ chỉ số 3, lấy 2 ký tự
    string nam = ngayStr.substr(6, 4);         // Từ chỉ số 6, lấy 4 ký tự
    string tuChiSo6DenCuoi = ngayStr.substr(6);   // Không truyền độ dài -> lấy đến hết

    cout << "Ngay: " << ngay << endl;
    cout << "Thang: " << thang << endl;
    cout << "Nam: " << nam << endl;
    cout << "Tu chi so 6 den cuoi: " << tuChiSo6DenCuoi << endl;
    return 0;
}
```

**Output đã kiểm chứng:**

```
Ngay: 15
Thang: 07
Nam: 2026
Tu chi so 6 den cuoi: 2026
```

Với chuỗi `"15/07/2026"`, chỉ số `0-1` là ngày (`"15"`), chỉ số `3-4` là tháng (`"07"`, bỏ qua dấu `/` ở chỉ số 2), và chỉ số `6` trở đi là năm (`"2026"`).

### Ví dụ 3: Tìm kiếm với .find() — cả hai trường hợp tìm thấy và không tìm thấy (Mục tiêu: nắm cách dùng find và npos)

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string email = "hocvien@gmail.com";

    size_t viTri = email.find('@');
    cout << "Vi tri cua '@': " << viTri << endl;

    size_t viTriKhongCo = email.find('#');
    cout << "Vi tri cua '#' (khong ton tai): " << viTriKhongCo << endl;

    if (viTriKhongCo == string::npos) {
        cout << "Xac nhan: '#' khong ton tai trong chuoi (npos)" << endl;
    }
    return 0;
}
```

**Output đã kiểm chứng:**

```
Vi tri cua '@': 7
Vi tri cua '#' (khong ton tai): 18446744073709551615
Xac nhan: '#' khong ton tai trong chuoi (npos)
```

Ký tự `@` được tìm thấy tại chỉ số `7`. Nhưng khi tìm ký tự `#` (không có trong chuỗi), kết quả trả về là một **con số cực lớn** (`18446744073709551615`) — đây chính là giá trị thực sự của `string::npos`, và nó trông rất kỳ lạ nếu in trực tiếp ra màn hình. Vì vậy, luôn phải so sánh kết quả với `string::npos` để kiểm tra, thay vì tự suy đoán con số cụ thể.

### Ví dụ 4: Nối chuỗi bằng .append() (Mục tiêu: nắm cách dùng thêm một hàm nối chuỗi khác)

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string ho = "Nguyen Van";
    ho.append(" A");

    string thongBao = "Xin chao";
    thongBao.append(", ").append("ban").append("!");   // Có thể nối tiếp nhiều lần liên tục

    cout << "Sau khi append: " << ho << endl;
    cout << "Chuoi noi tiep: " << thongBao << endl;
    return 0;
}
```

**Output đã kiểm chứng:**

```
Sau khi append: Nguyen Van A
Chuoi noi tiep: Xin chao, ban!
```

`.append()` hoạt động tương tự `+=` đã học ở bài trước, nhưng có một điểm đặc biệt: vì nó trả về chính chuỗi đã được nối, bạn có thể **nối liên tiếp nhiều lần** (`thongBao.append(...).append(...)`) trong cùng một dòng lệnh.

### Ví dụ 5: Ứng dụng thực tế — tách họ và tên riêng (Mục tiêu: kết hợp find và substr để giải quyết bài toán thực tế)

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string hoTenDayDu = "Nguyen Van An";

    size_t viTriCachCuoi = hoTenDayDu.find_last_of(' ');   // Tìm khoảng trắng CUỐI CÙNG
    string ho = hoTenDayDu.substr(0, viTriCachCuoi);
    string ten = hoTenDayDu.substr(viTriCachCuoi + 1);

    cout << "Ho va ten dem: " << ho << endl;
    cout << "Ten: " << ten << endl;
    return 0;
}
```

**Output đã kiểm chứng:**

```
Ho va ten dem: Nguyen Van
Ten: An
```

`find_last_of(' ')` (một hàm anh em của `.find()`, tìm từ **cuối chuỗi trở về**) tìm ra vị trí khoảng trắng cuối cùng — từ đó, `.substr()` được dùng hai lần để cắt lấy phần "họ và tên đệm" (trước khoảng trắng) và phần "tên" (sau khoảng trắng).

### Ví dụ 6: Ứng dụng thực tế — kiểm tra email có chứa @ hay không (Mục tiêu: kết hợp find và npos vào bài toán kiểm tra định dạng)

```cpp
#include <iostream>
#include <string>
using namespace std;

bool laEmailHopLe(string email) {
    return email.find('@') != string::npos;
}

int main() {
    string a = "hocvien@example.com";
    string b = "khong_hop_le";

    cout << a << " -> " << (laEmailHopLe(a) ? "Hop le" : "Khong hop le") << endl;
    cout << b << " -> " << (laEmailHopLe(b) ? "Hop le" : "Khong hop le") << endl;
    return 0;
}
```

**Output đã kiểm chứng:**

```
hocvien@example.com -> Hop le
khong_hop_le -> Khong hop le
```

Đây là một cách kiểm tra định dạng email **rất cơ bản** (chỉ kiểm tra sự tồn tại của ký tự `@`, chưa đầy đủ để xác nhận một email hợp lệ trong thực tế), nhưng minh họa rõ cách kết hợp `.find()` với `string::npos` để trả lời câu hỏi "chuỗi này có chứa ký tự/chuỗi con đó hay không".

## 6. Phần Chú Ý Và Lỗi Hay Gặp

- **So sánh kết quả của `.find()` với `-1` thay vì `string::npos`**: đây là lỗi rất phổ biến với người quen dùng ngôn ngữ khác — trong C++, giá trị "không tìm thấy" là `string::npos` (một số cực lớn), không phải `-1`. Viết `== -1` với biến `size_t` tình cờ vẫn đúng, nhưng nếu gán kết quả vào biến `int` rồi so sánh thì dễ sai; hãy luôn dùng `string::npos`.
- **Nhầm lẫn tham số của `.substr()`**: tham số thứ hai là **số lượng ký tự cần lấy**, không phải "vị trí kết thúc" — viết `substr(2, 5)` nghĩa là "bắt đầu từ chỉ số 2, lấy 5 ký tự", chứ không phải "lấy từ chỉ số 2 đến chỉ số 5".
- **Truyền vị trí bắt đầu vượt quá độ dài chuỗi cho `.substr()`**: nếu vị trí bắt đầu lớn hơn độ dài thực tế của chuỗi, chương trình sẽ ném ngoại lệ `out_of_range` khi chạy (vị trí đúng bằng độ dài thì chỉ trả về chuỗi rỗng) — nên cẩn trọng kiểm tra độ dài chuỗi trước khi cắt, đặc biệt với chuỗi có nội dung không cố định từ người dùng nhập vào.
- **Nghĩ rằng `.find()` tìm tất cả các vị trí xuất hiện**: `.find()` mặc định chỉ trả về vị trí xuất hiện **đầu tiên** — nếu cần tìm tất cả các vị trí xuất hiện của một ký tự/chuỗi con, cần gọi `.find()` nhiều lần với tham số vị trí bắt đầu tìm kiếm tiếp theo (kiến thức nâng cao hơn).
- **Quên rằng các hàm xử lý chuỗi phân biệt chữ hoa/chữ thường**: giống như phép so sánh `==` đã học ở bài trước, `.find("Apple")` sẽ **không** tìm thấy `"apple"` (chữ thường) trong chuỗi — luôn lưu ý điều này khi xử lý dữ liệu văn bản thực tế từ người dùng.
