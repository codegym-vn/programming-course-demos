# Tham Số Có Giá Trị Mặc Định (Default Parameters)

## 1. Mục Tiêu Bài Học

- Hiểu bản chất: **tham số có giá trị mặc định** là gì — một tham số được gán sẵn một giá trị ngay trong phần khai báo hàm, để dùng khi người gọi hàm không truyền đủ đối số.
- Nắm vững cú pháp: cách gán giá trị mặc định cho tham số, ví dụ `double soTien = 0.0`.
- Nắm chắc quy tắc quan trọng nhất: tham số có giá trị mặc định **phải đặt ở cuối** danh sách tham số.
- Ứng dụng được vào một hàm thực tế: tính giá sau giảm giá, với mức giảm mặc định là 0% nếu không chỉ định.

## 2. Giới Thiệu

Ở bài "Tham số và Đối số", bạn đã biết một hàm có thể nhận nhiều tham số, và mỗi lần gọi hàm, bạn phải truyền đủ đối số tương ứng cho từng tham số đó. Nhưng nếu một tham số **thường xuyên** mang một giá trị cố định, và chỉ thỉnh thoảng mới cần thay đổi thì sao? Việc bắt buộc phải gõ lại giá trị đó ở mọi lần gọi hàm sẽ khá dư thừa.

**Tham số có giá trị mặc định** giải quyết đúng vấn đề này: bạn "gán sẵn" một giá trị ngay trong phần khai báo hàm — nếu người gọi hàm không truyền đối số cho tham số đó, hàm sẽ tự động dùng giá trị đã gán sẵn; nếu người gọi vẫn muốn truyền một giá trị khác, hàm vẫn hoàn toàn chấp nhận và ưu tiên dùng giá trị mới đó.

## 3. Khái Niệm

- **Tham số có giá trị mặc định (Default Parameter)**: một tham số được gán sẵn một giá trị ngay trong phần khai báo hàm, cho phép người gọi hàm bỏ qua việc truyền đối số cho tham số đó.
- **Cú pháp**: `void inHoaDon(string ten, double soTien = 0.0)` — dấu `=` ngay sau tên tham số, theo sau là giá trị mặc định.
- **Quy tắc thứ tự**: tham số có giá trị mặc định phải nằm **ở cuối** danh sách tham số — không thể có một tham số **không** có giá trị mặc định đứng sau một tham số **đã có** giá trị mặc định.

## 4. Giải Thích

### 4.1. Cú Pháp Khai Báo Tham Số Mặc Định

```cpp
void inHoaDon(string ten, double soTien = 0.0) {
    cout << "Khach hang: " << ten << ", So tien: " << soTien << endl;
}
```

Khi gọi `inHoaDon("An", 500000)`, `soTien` nhận giá trị `500000`. Khi gọi `inHoaDon("Binh")` (không truyền `soTien`), tham số này tự động nhận giá trị mặc định `0.0`.

### 4.2. Có Thể Có Nhiều Tham Số Mặc Định

Một hàm có thể có nhiều tham số cùng mang giá trị mặc định — người gọi có thể truyền thiếu dần từ phải sang trái, và các tham số còn thiếu sẽ tự động dùng giá trị mặc định của chúng.

### 4.3. Quy Tắc Bắt Buộc: Tham Số Mặc Định Phải Ở Cuối

```cpp
void inThongTin(string ten, int tuoi = 18, string queQuan) { ... }  // LỖI
```

Đây là lỗi biên dịch, vì C++ xác định đối số theo đúng **vị trí** — nếu tham số có mặc định (`tuoi`) nằm giữa, còn tham số không có mặc định (`queQuan`) lại nằm sau nó, trình biên dịch sẽ không biết xử lý thế nào khi người gọi hàm bỏ qua `tuoi` nhưng vẫn muốn truyền `queQuan`.

## 5. Ví Dụ

Toàn bộ output và thông báo lỗi dưới đây đã được biên dịch, chạy thử thực tế để đảm bảo tính chính xác.

### Ví dụ 1: Tham số mặc định cơ bản (Mục tiêu: nắm cú pháp cơ bản nhất)

```cpp
#include <iostream>
#include <string>
using namespace std;

void inHoaDon(string ten, double soTien = 0.0) {
    cout << "Khach hang: " << ten << ", So tien: " << soTien << endl;
}

int main() {
    inHoaDon("Nguyen Van An", 500000);   // Truyền đủ 2 đối số
    inHoaDon("Tran Thi Binh");             // CHỈ truyền 1 đối số
    return 0;
}
```

**Output đã kiểm chứng:**

```
Khach hang: Nguyen Van An, So tien: 500000
Khach hang: Tran Thi Binh, So tien: 0
```

Lần gọi thứ hai không truyền `soTien`, nhưng hàm vẫn chạy được bình thường, tự động dùng giá trị mặc định `0.0`.

### Ví dụ 2: Nhiều tham số mặc định cùng lúc (Mục tiêu: hiểu cách truyền thiếu dần từ phải sang trái)

```cpp
#include <iostream>
#include <string>
using namespace std;

void inThongTin(string ten, int tuoi = 18, string queQuan = "Ha Noi") {
    cout << "Ten: " << ten << ", Tuoi: " << tuoi << ", Que quan: " << queQuan << endl;
}

int main() {
    inThongTin("An", 20, "Da Nang");   // Truyền đủ 3 đối số
    inThongTin("Binh", 22);             // Truyền 2 đối số
    inThongTin("Cuong");                // Chỉ truyền 1 đối số
    return 0;
}
```

**Output đã kiểm chứng:**

```
Ten: An, Tuoi: 20, Que quan: Da Nang
Ten: Binh, Tuoi: 22, Que quan: Ha Noi
Ten: Cuong, Tuoi: 18, Que quan: Ha Noi
```

Càng truyền ít đối số, các tham số còn thiếu (tính từ phải sang) càng tự động dùng giá trị mặc định của chúng — `Binh` thiếu `queQuan` nên dùng `"Ha Noi"`; `Cuong` thiếu cả `tuoi` lẫn `queQuan` nên cả hai đều dùng giá trị mặc định.

### Ví dụ 3: Lỗi — tham số không mặc định đứng sau tham số có mặc định (Mục tiêu: khắc sâu quy tắc bắt buộc)

```cpp
#include <iostream>
#include <string>
using namespace std;

void inThongTin(string ten, int tuoi = 18, string queQuan) {
    cout << "Ten: " << ten << ", Tuoi: " << tuoi << ", Que quan: " << queQuan << endl;
}

int main() {
    inThongTin("An", 20, "Da Nang");
    return 0;
}
```

**Thông báo lỗi biên dịch thực tế (g++):**

```
error: default argument missing for parameter 3 of 'void inThongTin(std::string, int, std::string)'
note: ...following parameter 2 which has a default argument
```

Trình biên dịch báo lỗi rõ ràng: tham số thứ 3 (`queQuan`) thiếu giá trị mặc định, trong khi tham số thứ 2 (`tuoi`, đứng trước nó) đã có — vi phạm đúng quy tắc đã nêu ở mục 4.3. Cách sửa là đưa tham số không mặc định lên trước, ví dụ `void inThongTin(string ten, string queQuan, int tuoi = 18)`.

### Ví dụ 4: Ứng dụng thực tế — hàm tính giá sau giảm giá (Mục tiêu: ứng dụng vào bài toán cụ thể)

```cpp
#include <iostream>
using namespace std;

double tinhGiaSauGiam(double giaGoc, double phanTramGiam = 0) {
    double soTienGiam = giaGoc * phanTramGiam / 100;
    return giaGoc - soTienGiam;
}

int main() {
    double gia1 = tinhGiaSauGiam(200000, 10);   // Giảm 10%
    cout << "Gia sau khi giam 10%: " << gia1 << endl;

    double gia2 = tinhGiaSauGiam(200000);        // KHÔNG truyền % giảm
    cout << "Gia khong giam gia: " << gia2 << endl;
    return 0;
}
```

**Output đã kiểm chứng:**

```
Gia sau khi giam 10%: 180000
Gia khong giam gia: 200000
```

Nhờ `phanTramGiam = 0` làm giá trị mặc định, hàm `tinhGiaSauGiam` có thể được gọi cho cả hai tình huống: có áp dụng giảm giá (truyền thêm đối số thứ hai) và không áp dụng giảm giá (chỉ cần truyền giá gốc) — mà không cần viết hai hàm riêng biệt cho từng trường hợp.

### Xem giá trị mặc định bị ghi đè từng bước

Bấm **Bước tiếp** để xem ô tham số có giá trị điền sẵn (chữ xám nghiêng) được dùng hay bị thay thế:

- Tab **Truyền đủ / thiếu dần đối số**: ô nào nhận chip đối số thì chữ xám được thay bằng giá trị mới; ô không nhận chip giữ chữ xám "(mặc định)" và đổi viền xanh.
- Tab **Quy tắc: mặc định ở cuối**: chỗ trống ở giữa dòng gọi báo lỗi cú pháp; hàm khai báo sai thì ô thứ 3 hiện đỏ; sau khi chuyển ô mặc định xuống cuối, lời gọi hai đối số chạy được.
- Tab **Ứng dụng: tinhGiaSauGiam**: cùng một hàm nhưng ô `phanTramGiam` nhận 10 ở lần gọi đầu và giữ 0 ở lần gọi sau, nên `g1` và `g2` ra hai giá trị khác nhau.

## 6. Phần Chú Ý Và Lỗi Hay Gặp

- **Đặt tham số không mặc định sau tham số có mặc định**: đây là lỗi cú pháp nghiêm trọng nhất của bài học (xem lại Ví dụ 3) — luôn sắp xếp tham số theo đúng thứ tự: tham số bắt buộc trước, tham số có giá trị mặc định ở cuối.
- **Nghĩ rằng có thể "bỏ qua" một tham số ở giữa khi gọi hàm**: C++ xác định đối số hoàn toàn theo vị trí — không thể gọi `inThongTin("An", , "Da Nang")` để "bỏ qua" `tuoi` mà vẫn truyền `queQuan`; chỉ có thể bỏ bớt đối số từ **phải sang trái**, không thể bỏ ở giữa.
- **Khai báo giá trị mặc định ở cả phần khai báo (prototype) lẫn phần định nghĩa hàm**: nếu hàm được khai báo tách rời (prototype trước, định nghĩa sau — sẽ học ở bài riêng về khai báo và định nghĩa hàm), giá trị mặc định chỉ được ghi **một lần duy nhất**, thường là ở prototype, còn phần định nghĩa viết tham số như bình thường (không có `= ...`). Ghi lặp lại ở cả hai nơi sẽ gây lỗi biên dịch.
- **Không thấy được lợi ích thực tế của tham số mặc định**: như Ví dụ 4, giá trị của kỹ thuật này thể hiện rõ nhất khi một hàm có tham số **thường xuyên** giữ nguyên một giá trị nhất định — giúp người gọi hàm không phải lặp lại giá trị đó ở mọi lần gọi, trong khi vẫn giữ được sự linh hoạt để thay đổi khi cần.
- **Nhầm lẫn giữa "không truyền đối số" và "truyền giá trị 0 hoặc rỗng"**: đây là hai việc hoàn toàn khác nhau — `tinhGiaSauGiam(200000)` (không truyền `phanTramGiam`) và `tinhGiaSauGiam(200000, 0)` (truyền tường minh giá trị `0`) cho ra kết quả giống nhau trong ví dụ này, nhưng về bản chất là hai lời gọi khác nhau, và không phải lúc nào giá trị mặc định cũng trùng với "giá trị rỗng" một cách ngẫu nhiên như vậy.
