# Truy Cập Và Duyệt Từng Ký Tự Trong Chuỗi

## 1. Mục Tiêu Bài Học

- Hiểu bản chất: `std::string` thực chất là một **dãy ký tự** có thể truy cập từng phần tử bằng chỉ số, tương tự như mảng đã học ở phần trước.
- Nắm vững cú pháp: dùng toán tử `[]` để truy cập (và thậm chí gán lại) ký tự tại một vị trí cụ thể, và dùng vòng lặp `for` để duyệt qua toàn bộ chuỗi.
- Ứng dụng được vào các bài toán thực tế: đếm số ký tự thỏa điều kiện (như đếm nguyên âm), đảo ngược một chuỗi.
- Hiểu được sự khác biệt an toàn giữa `[]` và `.at()` khi truy cập ngoài phạm vi chuỗi.

## 2. Giới Thiệu

Bạn đã học cách xử lý toàn bộ chuỗi như một khối thống nhất — nối chuỗi, so sánh chuỗi, cắt chuỗi con bằng `.substr()`. Nhưng đôi khi, bạn cần xử lý chuỗi ở mức độ chi tiết hơn: xét **từng ký tự một**. Ví dụ: đếm xem trong một câu có bao nhiêu nguyên âm, hay đảo ngược thứ tự các ký tự trong một từ.

Điều thú vị là `std::string`, về bản chất, hoạt động rất giống với **mảng ký tự** đã học ở phần Mảng — bạn có thể dùng chỉ số (bắt đầu từ 0) để truy cập từng ký tự, và dùng vòng lặp `for` để duyệt qua toàn bộ chuỗi, áp dụng đúng những kỹ thuật duyệt mảng đã thành thạo trước đó.

## 3. Khái Niệm

- **Truy cập ký tự bằng chỉ số**: dùng cú pháp `tenChuoi[chiSo]` để lấy ra (hoặc gán lại) ký tự tại một vị trí cụ thể trong chuỗi — chỉ số cũng bắt đầu từ `0`, giống mảng.
- `.at(chiSo)`: một cách khác để truy cập ký tự, tương tự `[]`, nhưng có kiểm tra an toàn — sẽ báo lỗi rõ ràng nếu chỉ số vượt quá phạm vi hợp lệ.
- **Duyệt chuỗi (String Traversal)**: kỹ thuật dùng vòng lặp `for` chạy từ chỉ số `0` đến `length() - 1` để lần lượt xử lý từng ký tự trong chuỗi.

## 4. Giải Thích

### 4.1. Truy Cập Ký Tự Bằng []

```cpp
string tenChuoi = "Hello";
char kyTuDau = tenChuoi[0];   // 'H'
tenChuoi[0] = 'J';            // Gán lại ký tự đầu tiên -> chuỗi trở thành "Jello"
```

Toán tử `[]` cho phép cả **đọc** và **gán lại** giá trị của một ký tự cụ thể trong chuỗi, giống hệt cách bạn thao tác với phần tử của mảng.

### 4.2. Duyệt Toàn Bộ Chuỗi Bằng Vòng Lặp for

```cpp
string tenChuoi = "Hello";
for (int i = 0; i < tenChuoi.length(); i++) {
    char c = tenChuoi[i];
    // Xử lý ký tự c
}
```

Công thức này gần như giống hệt công thức duyệt mảng đã học — chỉ khác ở chỗ điều kiện dừng dùng `.length()` của chuỗi thay vì biến `n` cố định của mảng. (`.length()` trả về số không dấu nên trình biên dịch có thể cảnh báo khi so sánh với `int i`; cảnh báo này vô hại ở các ví dụ trong bài.)

### 4.3. Sự Khác Biệt An Toàn Giữa [] Và .at()

Cả hai cách đều dùng để truy cập ký tự tại một vị trí, nhưng chúng phản ứng khác nhau hoàn toàn khi chỉ số truy cập **vượt quá phạm vi hợp lệ** của chuỗi: `[]` không hề kiểm tra gì cả (giống lỗi out-of-bounds đã học ở phần Mảng — hành vi không xác định), còn `.at()` sẽ chủ động phát hiện và báo lỗi rõ ràng ngay lập tức. Chi tiết minh chứng cụ thể ở Ví dụ 5.

## 5. Ví Dụ

Toàn bộ output dưới đây đã được biên dịch và chạy thử thực tế để kiểm chứng.

### Ví dụ 1: Truy cập và gán lại ký tự bằng [] (Mục tiêu: nắm cú pháp cơ bản)

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string ten = "Hello";

    cout << "ten[0] = " << ten[0] << endl;
    cout << "ten[1] = " << ten[1] << endl;
    cout << "ten[4] = " << ten[4] << endl;

    ten[0] = 'J';
    cout << "Sau khi doi ky tu dau: " << ten << endl;
    return 0;
}
```

**Output đã kiểm chứng:**

```
ten[0] = H
ten[1] = e
ten[4] = o
Sau khi doi ky tu dau: Jello
```

`"Hello"` có 5 ký tự với chỉ số từ `0` đến `4` — `ten[4]` chính là ký tự **cuối cùng** (`'o'`), không phải `ten[5]` như nhiều người mới học lầm tưởng (giống quy tắc chỉ số của mảng).

### Ví dụ 2: Duyệt toàn bộ chuỗi bằng vòng lặp for (Mục tiêu: nắm kỹ thuật duyệt chuỗi)

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string tu = "C++";

    for (int i = 0; i < tu.length(); i++) {
        cout << "Ky tu tai chi so " << i << ": " << tu[i] << endl;
    }
    return 0;
}
```

**Output đã kiểm chứng:**

```
Ky tu tai chi so 0: C
Ky tu tai chi so 1: +
Ky tu tai chi so 2: +
```

### Ví dụ 3: Đếm số nguyên âm trong một câu (Mục tiêu: ứng dụng thực tế, kết hợp duyệt chuỗi với điều kiện)

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string cau = "Hello World";
    int demNguyenAm = 0;

    for (int i = 0; i < cau.length(); i++) {
        char c = cau[i];
        if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u' ||
            c == 'A' || c == 'E' || c == 'I' || c == 'O' || c == 'U') {
            demNguyenAm++;
        }
    }

    cout << "So nguyen am trong '" << cau << "': " << demNguyenAm << endl;
    return 0;
}
```

**Output đã kiểm chứng:**

```
So nguyen am trong 'Hello World': 3
```

Câu `"Hello World"` có đúng 3 nguyên âm (`e`, `o`, `o`) — kỹ thuật đếm này áp dụng đúng khuôn mẫu "biến tích lũy" đã học ở phần Mảng, chỉ khác là duyệt qua từng ký tự của chuỗi thay vì từng phần tử của mảng số.

### Ví dụ 4: Đảo ngược một chuỗi (Mục tiêu: ứng dụng duyệt ngược vào chuỗi)

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string goc = "Xin chao";
    string daoNguoc = "";

    for (int i = goc.length() - 1; i >= 0; i--) {
        daoNguoc += goc[i];   // Nối từng ký tự, bắt đầu từ cuối về đầu
    }

    cout << "Chuoi goc: " << goc << endl;
    cout << "Chuoi dao nguoc: " << daoNguoc << endl;
    return 0;
}
```

**Output đã kiểm chứng:**

```
Chuoi goc: Xin chao
Chuoi dao nguoc: oahc niX
```

Kỹ thuật này áp dụng đúng cách duyệt ngược đã học ở phần Mảng (`i = n - 1` giảm dần về `0`), kết hợp với toán tử `+=` để xây dựng dần chuỗi kết quả theo thứ tự ngược lại.

### Ví dụ 5: So sánh [] và .at() khi truy cập ngoài phạm vi (Mục tiêu: hiểu sự khác biệt an toàn quan trọng)

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "abc";   // Chỉ có 3 ký tự, chỉ số hợp lệ là 0-2

    cout << "Dung [] truy cap chi so 10: " << s[10] << endl;
    cout << "Chuong trinh van chay den day (khong bao loi gi ca)" << endl;

    cout << "Dung .at() truy cap chi so 10: " << s.at(10) << endl;
    cout << "Dong nay se KHONG BAO GIO duoc in ra" << endl;
    return 0;
}
```

**Output đã kiểm chứng (với g++):**

```
Dung [] truy cap chi so 10: h
Chuong trinh van chay den day (khong bao loi gi ca)
```

**Sau đó chương trình dừng đột ngột (Aborted), với thông báo lỗi:**

```
terminate called after throwing an instance of 'std::out_of_range'
  what():  basic_string::at: __n (which is 10) >= this->size() (which is 3)
```

Đây là bằng chứng rõ ràng nhất: `s[10]` (dùng `[]`) truy cập vào một vị trí không hợp lệ, nhưng chương trình **không hề dừng lại hay báo lỗi** — nó chỉ in ra một ký tự rác không đáng tin cậy (`'h'` trong lần chạy này, mỗi máy và mỗi lần chạy có thể khác) rồi tiếp tục chạy bình thường, y hệt lỗi out-of-bounds của mảng đã học trước đó. Ngược lại, `s.at(10)` phát hiện ngay lập tức chỉ số không hợp lệ, và chủ động "ném" ra một lỗi rõ ràng (`std::out_of_range`), khiến chương trình dừng lại có kiểm soát — dòng lệnh phía sau `s.at(10)` không bao giờ được thực thi. (Nội dung dòng `what()` có thể khác chút tùy trình biên dịch.)

### Xem duyệt chuỗi từng bước

Bấm **Bước tiếp** để xem từng ô của chuỗi được đọc, ghi và duyệt qua:

- Tab **Đọc và ghi bằng []**: ô 0 đổi từ `H` sang `J` ngay trên dải ô, còn các ô khác giữ nguyên.
- Tab **Duyệt: đếm nguyên âm**: biến `i`, ký tự `c` và bộ đếm `demNguyenAm` đổi theo từng lượt; các ô nguyên âm sáng xanh, ô còn lại mờ đi khi đã được xét.
- Tab **[] và .at() ngoài phạm vi**: dải ô của `s` chỉ có 3 ô, vùng ngoài chuỗi vẽ bằng các ô `?`; `[]` đi thẳng vào vùng đó mà không báo lỗi, còn `.at()` dừng chương trình và dòng cuối bị làm mờ vì không bao giờ chạy.

Điều rút ra: `string` là dãy `char` có chỉ số `0` đến `length() - 1`; `[]` không kiểm tra biên, còn `.at()` kiểm tra và ném `out_of_range`.

## 6. Phần Chú Ý Và Lỗi Hay Gặp

- **Truy cập ngoài phạm vi chuỗi bằng `[]` mà không hay biết**: đây là lỗi nguy hiểm nhất (xem lại Ví dụ 5) — vì `[]` không tự kiểm tra, chương trình có thể "âm thầm" chạy sai mà không có bất kỳ cảnh báo nào. Nếu không chắc chắn chỉ số truy cập luôn hợp lệ, hãy cân nhắc dùng `.at()` để được bảo vệ an toàn hơn.
- **Nhầm lẫn `.length()` với chỉ số ký tự cuối cùng**: chuỗi có `n` ký tự thì chỉ số hợp lệ chạy từ `0` đến `n - 1` — dùng `tenChuoi[tenChuoi.length()]` (không trừ đi 1) là truy cập ngoài phạm vi, giống hệt lỗi off-by-one đã học ở phần Mảng. (Riêng với `std::string`, đọc `tenChuoi[tenChuoi.length()]` còn cho ký tự kết thúc `'\0'` mà không lỗi, nhưng đừng dựa vào điều này.)
- **Quên rằng mỗi ký tự trong chuỗi có kiểu dữ liệu `char`, không phải `string`**: khi lấy `tenChuoi[i]`, kết quả trả về là một ký tự đơn (`char`, dùng dấu nháy đơn `'x'`), không phải một chuỗi nhỏ — điều này ảnh hưởng đến cách bạn so sánh nó (`c == 'a'`, không phải `c == "a"`).
- **Không xử lý cả chữ hoa lẫn chữ thường khi kiểm tra điều kiện ký tự**: như Ví dụ 3, nếu chỉ kiểm tra nguyên âm chữ thường mà quên chữ hoa (hoặc ngược lại), kết quả đếm sẽ bị thiếu sót — luôn cân nhắc cả hai trường hợp khi xử lý văn bản do người dùng nhập vào.
- **Dùng `[]` với chỉ số âm hoặc kiểu dữ liệu không phải số nguyên**: dù C++ không luôn báo lỗi biên dịch ngay, việc dùng chỉ số âm hoặc các giá trị bất thường khác sẽ dẫn đến hành vi không xác định tương tự Ví dụ 5 — luôn đảm bảo chỉ số nằm trong khoảng `0` đến `length() - 1` trước khi truy cập.
