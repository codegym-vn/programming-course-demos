# Khai Báo, Khởi Tạo Và Các Phép Toán Cơ Bản Với std::string

## 1. Mục Tiêu Bài Học

- Hiểu bản chất: `std::string` là gì — một kiểu dữ liệu hiện đại, linh hoạt để lưu trữ và xử lý chuỗi ký tự trong C++.
- Nắm vững cú pháp: nhiều cách khai báo và khởi tạo một chuỗi.
- Nắm vững các phép toán cơ bản: nối chuỗi (`+`, `+=`), so sánh chuỗi (`==`, `!=`, `<`, `>`), và gán lại giá trị.
- Tránh được lỗi phổ biến nhất khi mới làm quen với chuỗi: cố nối hai chuỗi ký tự thuần (literal) trực tiếp mà không qua `std::string`.
- Quan sát chuỗi như một dải ký tự co giãn bằng hoạt động mô phỏng.

## 2. Giới Thiệu

Ở các bài học trước, bạn đã dùng `string` để lưu họ tên, mật khẩu, hay các thông tin dạng văn bản khác. Nhưng để thực sự làm chủ được kiểu dữ liệu này, bạn cần hiểu sâu hơn về cách nó hoạt động: có bao nhiêu cách để tạo ra một chuỗi, và những phép toán nào có thể thực hiện trực tiếp trên chúng.

Điều thú vị của `std::string` (viết tắt của "standard string" — chuỗi chuẩn) là nó cho phép bạn thao tác với văn bản gần như tự nhiên như thao tác với số: bạn có thể "cộng" hai chuỗi lại với nhau bằng dấu `+`, "so sánh" hai chuỗi bằng `==`, hay gán chuỗi mới cho một biến đã tồn tại — tất cả đều rất trực quan, khác hẳn với cách xử lý chuỗi phức tạp hơn nhiều của ngôn ngữ C nguyên thủy (sẽ được tìm hiểu ở bài cuối cùng của phần này).

## 3. Khái Niệm

- `std::string`: kiểu dữ liệu chuẩn của C++ (thường dùng gọn là `string` sau khi có `using namespace std;`) dùng để lưu trữ một chuỗi ký tự có độ dài linh hoạt.
- **Khởi tạo (Initialization)**: quá trình gán giá trị ban đầu cho một chuỗi ngay tại thời điểm khai báo.
- **Nối chuỗi (Concatenation)**: thao tác ghép nhiều chuỗi lại với nhau thành một chuỗi mới, thực hiện bằng toán tử `+` hoặc `+=`.
- **So sánh chuỗi (String Comparison)**: thao tác đối chiếu hai chuỗi bằng các toán tử `==`, `!=`, `<`, `>` — trong đó `<` và `>` so sánh theo **thứ tự từ điển** (alphabetical order), không phải theo độ dài chuỗi.

## 4. Giải Thích

### 4.1. Các Cách Khai Báo Và Khởi Tạo Chuỗi

```cpp
string s1;                    // Khai báo rỗng, chưa có giá trị
string s2 = "Xin chao";       // Khai báo và khởi tạo bằng dấu =
string s3("Viet Nam");        // Khởi tạo bằng dấu ngoặc tròn
string s4 = s2;               // Sao chép giá trị từ một chuỗi khác
```

Cả bốn cách đều hợp lệ và cho ra kết quả tương đương — sự khác biệt chỉ nằm ở phong cách viết code, tùy sở thích của người lập trình.

### 4.2. Nối Chuỗi Bằng + Và +=

Toán tử `+` ghép hai chuỗi thành một chuỗi mới; toán tử `+=` nối thêm nội dung vào **chính chuỗi hiện tại**, không tạo biến mới.

Với phép `+`, quy tắc cần nhớ là: **ít nhất một vế phải là `std::string`**. Ghép một `string` với chuỗi viết trong ngoặc kép, hoặc với một ký tự đơn như `'x'`, đều hợp lệ. Riêng số thì không tự đổi thành chữ: muốn nối số vào chuỗi, hãy đổi bằng `to_string` (ví dụ `"Tuoi: " + to_string(20)`).

### 4.3. So Sánh Chuỗi

Các toán tử `==`, `!=` so sánh xem hai chuỗi có hoàn toàn giống nhau hay không (phân biệt chữ hoa/thường). Các toán tử `<`, `>` so sánh theo **thứ tự từ điển** — giống cách so sánh khi sắp xếp trong từ điển hoặc danh bạ điện thoại: `"apple" < "banana"` là đúng, vì chữ cái `a` đứng trước `b`. Cơ chế chi tiết được học ở bài kế tiếp.

### 4.4. Gán Lại Giá Trị Cho Chuỗi

Một biến chuỗi đã khai báo có thể được gán lại giá trị mới bất cứ lúc nào bằng dấu `=`, giống hệt cách gán lại giá trị cho biến số — giá trị cũ sẽ hoàn toàn bị thay thế.

## 5. Ví Dụ

Toàn bộ output và thông báo lỗi dưới đây được lấy từ lần biên dịch và chạy thử thực tế.

### Ví dụ 1: Bốn cách khai báo và khởi tạo chuỗi (Mục tiêu: nắm cú pháp cơ bản)

```cpp
string s1;
string s2 = "Xin chao";
string s3("Viet Nam");
string s4 = s2;

cout << "s1 = [" << s1 << "]" << endl;
cout << "s2 = " << s2 << endl;
cout << "s3 = " << s3 << endl;
cout << "s4 = " << s4 << endl;
```

**Output đã kiểm chứng:**

```
s1 = []
s2 = Xin chao
s3 = Viet Nam
s4 = Xin chao
```

Chuỗi `s1` khi in ra không có nội dung gì bên trong cặp dấu ngoặc vuông (vì nó được khởi tạo rỗng) — đây là hành vi hoàn toàn bình thường và an toàn của `std::string`, khác với `char[]` kiểu C có thể chứa dữ liệu rác nếu không khởi tạo cẩn thận.

### Ví dụ 2: Nối chuỗi bằng toán tử + (Mục tiêu: nắm phép toán nối chuỗi)

```cpp
string ho = "Nguyen";
string ten = "An";
string hoTenDayDu = ho + " " + ten;

cout << "Ho ten day du: " << hoTenDayDu << endl;

string loiChao = "Xin chao, " + hoTenDayDu + "!";
cout << loiChao << endl;
```

**Output đã kiểm chứng:**

```
Ho ten day du: Nguyen An
Xin chao, Nguyen An!
```

Toán tử `+` có thể nối nhiều chuỗi liên tiếp trong cùng một biểu thức, kể cả kết hợp giữa biến chuỗi (`ho`, `ten`) và chuỗi ký tự viết trực tiếp (`" "`, `"!"`). Biểu thức được tính từ trái sang phải: `"Xin chao, " + hoTenDayDu` đã có một vế là `std::string` nên ra một `std::string`, rồi mới ghép tiếp với `"!"`.

### Ví dụ 3: So sánh chuỗi bằng ==, !=, < (Mục tiêu: nắm phép toán so sánh)

```cpp
string a = "apple";
string b = "banana";
string c = "apple";

cout << "a == c: " << (a == c) << endl;
cout << "a == b: " << (a == b) << endl;
cout << "a != b: " << (a != b) << endl;
cout << "a < b: " << (a < b) << endl;
cout << "b < a: " << (b < a) << endl;
```

**Output đã kiểm chứng:**

```
a == c: 1
a == b: 0
a != b: 1
a < b: 1
b < a: 0
```

`a == c` cho ra `1` (đúng) vì cả hai đều là `"apple"`. `a < b` cho ra `1` (đúng) vì so sánh theo thứ tự từ điển, `"apple"` đứng trước `"banana"` (do chữ `a` đứng trước chữ `b` trong bảng chữ cái).

### Ví dụ 4: Gán lại giá trị và nối thêm bằng += (Mục tiêu: nắm cách cập nhật giá trị chuỗi)

```cpp
string thongBao = "Dang xu ly...";
cout << "Truoc: " << thongBao << endl;

thongBao = "Hoan tat!";              // Ghi đè hoàn toàn giá trị cũ
cout << "Sau: " << thongBao << endl;

thongBao += " Cam on ban.";          // Nối thêm vào giá trị hiện tại
cout << "Sau khi cong them: " << thongBao << endl;
```

**Output đã kiểm chứng:**

```
Truoc: Dang xu ly...
Sau: Hoan tat!
Sau khi cong them: Hoan tat! Cam on ban.
```

Lưu ý sự khác biệt: dùng `=` sẽ **xóa hoàn toàn** giá trị cũ và thay bằng giá trị mới, còn dùng `+=` sẽ **giữ nguyên** giá trị hiện tại và chỉ nối thêm nội dung mới vào phía sau.

### Ví dụ 5: Lỗi kinh điển — cố nối hai chuỗi ký tự thuần trực tiếp (Mục tiêu: tránh lỗi phổ biến nhất)

```cpp
string ketQua = "Hello" + "World";   // Cả hai đều là chuỗi ký tự C thuần, không phải std::string
```

**Thông báo lỗi biên dịch thực tế:**

```
error: invalid operands of types 'const char [6]' and 'const char [6]' to binary 'operator+'
```

Đây là một lỗi rất bất ngờ với người mới học: `"Hello"` và `"World"` khi viết trực tiếp trong code không phải là đối tượng `std::string`, mà là **chuỗi ký tự kiểu C thuần** (`const char[]`) — và C++ không định nghĩa phép `+` cho hai chuỗi kiểu này cộng trực tiếp với nhau.

**Cách sửa:** chỉ cần đảm bảo **ít nhất một** trong hai vế là `std::string` thực sự:

```cpp
string ketQua = string("Hello") + "World";   // Đã sửa - hoạt động bình thường
cout << ketQua << endl;
```

**Output đã kiểm chứng sau khi sửa:**

```
HelloWorld
```

### Xem chuỗi lớn lên và thu nhỏ từng bước

Bấm **Bước tiếp** để xem mỗi chuỗi là một dải ô ký tự, có số thứ tự ô và nhãn độ dài:

- Tab **Khai báo và khởi tạo**: `s1` rỗng là dải không có ô nào (độ dài 0); `s4` là một dải riêng chép từ `s2`, nên đổi `s4` thành `"Hi"` thì `s2` vẫn nguyên.
- Tab **Nối (+, +=) và gán lại (=)**: phép `ho + " " + ten` ghép dần qua một chuỗi tạm; khi `+=`, các ô cũ giữ nguyên và chỉ mọc thêm ô ở đuôi, độ dài tăng từ 9 lên 21.
- Tab **Bẫy "Hello" + "World"**: chuỗi viết trong ngoặc kép có thêm ô `\0` ở cuối (nên `"Hello"` là `const char[6]`); bọc `string(...)` biến nó thành dải `std::string` thật.

## 6. Phần Chú Ý Và Lỗi Hay Gặp

- **Cố nối hai chuỗi ký tự thuần (literal) trực tiếp bằng `+`**: đây là lỗi biên dịch phổ biến nhất (xem lại Ví dụ 5) — luôn đảm bảo ít nhất một bên của phép `+` là một đối tượng `std::string` thực sự, không phải chuỗi ký tự viết trực tiếp trong dấu ngoặc kép.
- **Nhầm lẫn `=` (gán, ghi đè) và `+=` (nối thêm)**: dùng nhầm `=` khi ý định là nối thêm nội dung sẽ khiến toàn bộ nội dung cũ của chuỗi bị mất — luôn kiểm tra kỹ ý định của mình trước khi chọn toán tử.
- **Nghĩ rằng `<` và `>` so sánh độ dài chuỗi**: đây là hiểu lầm phổ biến — các toán tử này so sánh theo **thứ tự từ điển** (ký tự đầu tiên khác nhau sẽ quyết định kết quả), hoàn toàn không liên quan đến số lượng ký tự trong chuỗi. Ví dụ `"z" > "apple"` vẫn đúng, dù `"z"` ngắn hơn nhiều so với `"apple"`.
- **So sánh chuỗi mà quên phân biệt chữ hoa/chữ thường**: `"Apple" == "apple"` sẽ cho kết quả **sai** (không bằng nhau), vì `std::string` so sánh phân biệt chữ hoa/thường theo mặc định — nếu cần so sánh không phân biệt hoa/thường, cần xử lý thêm (kiến thức nâng cao hơn, chưa cần quan tâm ở bài này).
- **Cộng số trực tiếp vào biến chuỗi**: nếu `s` là `string` thì `s + 20` là lỗi vì số không tự đổi thành chữ — hãy dùng `s + to_string(20)`.
- **Không chắc chắn giá trị mặc định của chuỗi khai báo rỗng**: khi khai báo `string s1;` mà chưa gán giá trị, `s1` sẽ là một chuỗi **rỗng an toàn** (độ dài 0), khác hẳn với biến số nguyên `int x;` chưa khởi tạo (giá trị rác không xác định) — đây là một trong những ưu điểm về độ an toàn của `std::string`.
