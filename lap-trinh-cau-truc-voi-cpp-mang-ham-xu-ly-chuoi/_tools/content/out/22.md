# Chuyển Đổi Qua Lại Giữa Chuỗi Và Số

## 1. Mục Tiêu Bài Học

- Hiểu bản chất: vì sao đôi khi cần chuyển đổi qua lại giữa chuỗi (`string`) và số (`int`, `double`) trong C++.
- Nắm vững cách dùng `to_string()` để chuyển một giá trị số thành chuỗi.
- Nắm vững cách dùng `stoi()` và `stod()` để chuyển một chuỗi thành số nguyên hoặc số thực.
- Tránh được lỗi nghiêm trọng: chuyển đổi một chuỗi không hợp lệ thành số, gây ra lỗi khi chương trình đang chạy.
- Quan sát từng ký tự được đọc thành số (và nơi việc đọc dừng lại) bằng hoạt động mô phỏng.

## 2. Giới Thiệu

Bạn còn nhớ ở bài "Nhập xuất chuỗi", khi dùng `getline()` để đọc dữ liệu, kết quả luôn là một `string` — kể cả khi người dùng gõ vào một con số như `"150000"`. Nếu bạn cần **tính toán** với con số đó (ví dụ cộng thêm thuế), bạn không thể thực hiện phép nhân trực tiếp trên một `string` — bạn cần chuyển nó thành số trước.

Ngược lại, đôi khi bạn có một con số (kết quả của một phép tính) và cần **nối nó vào trong một câu thông báo** — nhưng toán tử `+` của chuỗi không hoạt động trực tiếp với số, bạn cần chuyển số đó thành chuỗi trước. C++ cung cấp sẵn các hàm để giải quyết cả hai chiều chuyển đổi này: `to_string()` (số → chuỗi) và `stoi()`/`stod()` (chuỗi → số).

## 3. Khái Niệm

- `to_string(giá_trị_số)`: hàm chuyển một giá trị số (`int`, `double`...) thành một chuỗi (`string`) tương ứng.
- `stoi(chuỗi)`: viết tắt của "string to integer" — chuyển một chuỗi thành số nguyên (`int`).
- `stod(chuỗi)`: viết tắt của "string to double" — chuyển một chuỗi thành số thực (`double`).
- `std::invalid_argument`: một loại lỗi (ngoại lệ) được C++ "ném ra" khi `stoi()` hoặc `stod()` được gọi với một chuỗi hoàn toàn không thể chuyển thành số hợp lệ.

## 4. Giải Thích

### 4.1. Chuyển Số Thành Chuỗi Với to_string()

```cpp
int tuoi = 20;
string chuoiTuoi = to_string(tuoi);   // "20"
```

Hàm này đặc biệt hữu ích khi bạn cần nối một giá trị số vào giữa một câu văn bản, vì toán tử `+` của `string` không thể tự động ghép trực tiếp với kiểu số.

### 4.2. Chuyển Chuỗi Thành Số Với stoi() Và stod()

```cpp
string chuoiSo = "123";
int soNguyen = stoi(chuoiSo);      // 123 (kiểu int)

string chuoiThapPhan = "8.75";
double soThapPhan = stod(chuoiThapPhan);   // 8.75 (kiểu double)
```

Dùng `stoi()` khi bạn cần kết quả là số nguyên, và `stod()` khi cần số thực có phần thập phân.

### 4.3. Lỗi Xảy Ra Khi Chuỗi Không Hợp Lệ

Nếu chuỗi truyền vào `stoi()` hoặc `stod()` không thể diễn giải thành số ngay từ ký tự đầu tiên (ví dụ `"xin chao"`), chương trình sẽ "ném ra" một lỗi gọi là **ngoại lệ (exception)** kiểu `std::invalid_argument` — nếu không được xử lý, chương trình sẽ dừng đột ngột. Chi tiết minh chứng cụ thể ở Ví dụ 4.

## 5. Ví Dụ

Các output dưới đây được lấy từ lần biên dịch và chạy thử thực tế.

### Ví dụ 1: Chuyển số thành chuỗi bằng to_string() (Mục tiêu: nắm cú pháp cơ bản)

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int tuoi = 20;
    double diem = 8.5;

    string chuoiTuoi = to_string(tuoi);
    string chuoiDiem = to_string(diem);

    string thongBao = "Ban " + to_string(tuoi) + " tuoi va dat " + to_string(diem) + " diem.";

    cout << "Chuoi tuoi: " << chuoiTuoi << " (do dai: " << chuoiTuoi.length() << ")" << endl;
    cout << "Chuoi diem: " << chuoiDiem << endl;
    cout << thongBao << endl;
    return 0;
}
```

**Output đã kiểm chứng:**

```
Chuoi tuoi: 20 (do dai: 2)
Chuoi diem: 8.500000
Ban 20 tuoi va dat 8.500000 diem.
```

Lưu ý một chi tiết quan trọng: `to_string(8.5)` không cho ra `"8.5"` như bạn có thể mong đợi, mà là `"8.500000"` — mặc định `to_string()` với số thực (`double`) luôn hiển thị đủ 6 chữ số sau dấu chấm. Nếu cần định dạng gọn hơn, cần xử lý thêm bằng các công cụ định dạng khác (kiến thức nâng cao hơn).

### Ví dụ 2: Chuyển chuỗi thành số nguyên bằng stoi() (Mục tiêu: nắm cú pháp chuyển đổi ngược)

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string chuoiSo = "123";
    int soNguyen = stoi(chuoiSo);
    cout << "Chuoi: " << chuoiSo << " -> So nguyen: " << soNguyen << endl;
    cout << "Sau khi chuyen, co the tinh toan: " << (soNguyen + 10) << endl;

    string chuoiSo2 = "45abc";
    int soNguyen2 = stoi(chuoiSo2);
    cout << "Chuoi: " << chuoiSo2 << " -> So nguyen: " << soNguyen2 << endl;
    return 0;
}
```

**Output đã kiểm chứng:**

```
Chuoi: 123 -> So nguyen: 123
Sau khi chuyen, co the tinh toan: 133
Chuoi: 45abc -> So nguyen: 45
```

Sau khi chuyển đổi, `soNguyen` trở thành một số `int` thực sự, có thể dùng trong các phép toán như `+ 10`. Một điều thú vị được phát hiện: `stoi("45abc")` vẫn thành công và cho ra `45` — hàm này chỉ đọc phần **số hợp lệ ở đầu chuỗi**, rồi dừng lại ngay khi gặp ký tự không phải số, không yêu cầu toàn bộ chuỗi phải là số.

### Ví dụ 3: Chuyển chuỗi thành số thực bằng stod() (Mục tiêu: nắm cú pháp cho số thập phân)

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string chuoiDiem = "8.75";
    double diem = stod(chuoiDiem);
    cout << "Chuoi: " << chuoiDiem << " -> So thuc: " << diem << endl;
    cout << "Diem cong them 1: " << (diem + 1) << endl;
    return 0;
}
```

**Output đã kiểm chứng:**

```
Chuoi: 8.75 -> So thuc: 8.75
Diem cong them 1: 9.75
```

### Ví dụ 4: Lỗi khi chuỗi không thể chuyển thành số (Mục tiêu: tránh lỗi nghiêm trọng nhất)

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string chuoiKhongPhaiSo = "xin chao";
    int ketQua = stoi(chuoiKhongPhaiSo);   // Chuỗi không bắt đầu bằng số hợp lệ
    cout << ketQua << endl;
    return 0;
}
```

**Kết quả khi chạy với g++:** chương trình dừng đột ngột (Aborted), với thông báo lỗi:

```
terminate called after throwing an instance of 'std::invalid_argument'
  what():  stoi
```

Đây là lỗi nghiêm trọng cần đặc biệt lưu ý: nếu dữ liệu chuỗi (thường đến từ người dùng nhập vào) không phải là một con số hợp lệ ngay từ ký tự đầu tiên, `stoi()` sẽ "ném" ra lỗi `std::invalid_argument`, và nếu không được xử lý, toàn bộ chương trình sẽ dừng lại bất ngờ — dòng lệnh `cout << ketQua` phía sau không bao giờ được thực thi.

### Ví dụ 5: Ứng dụng thực tế — tính giá tiền sau thuế từ dữ liệu người dùng nhập (Mục tiêu: kết hợp cả hai chiều chuyển đổi)

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string giaNhap;
    cin >> giaNhap;

    double gia = stod(giaNhap);          // Chuyển chuỗi người dùng nhập thành số để tính toán
    double giaSauThue = gia * 1.1;

    string thongBao = "Gia goc: " + giaNhap + " VND. Gia sau thue: " + to_string(giaSauThue) + " VND.";
    cout << thongBao << endl;
    return 0;
}
```

**Output đã kiểm chứng khi nhập** `150000`**:**

```
Gia goc: 150000 VND. Gia sau thue: 165000.000000 VND.
```

Đây là ví dụ điển hình kết hợp cả hai chiều chuyển đổi: dữ liệu người dùng nhập vào (`giaNhap`, kiểu `string`) được chuyển thành số (`stod`) để **tính toán**, rồi kết quả tính toán đó lại được chuyển ngược về chuỗi (`to_string`) để **hiển thị** trong một câu thông báo hoàn chỉnh.

### Xem chuyển đổi từng bước

Bấm **Bước tiếp** để xem từng ký tự của chuỗi được đọc thành số, và nơi việc đọc dừng lại:

- Tab **to_string và stoi/stod**: các số `0` thừa của `to_string(8.5)` được tô vàng; ở `stoi("45abc")`, ký tự `a` bị tô đỏ là chỗ dừng đọc và `bc` mờ đi; ở `stoi("8.75")`, việc đọc dừng ngay tại dấu chấm nên chỉ còn `8`.
- Tab **Lỗi "xin chao" và tính giá sau thuế**: ký tự đầu `x` đã đỏ nên không đọc được gì, chương trình dừng và dòng `cout` phía sau không chạy; sau đó chuỗi `"150000"` đi qua `stod`, phép nhân, rồi `to_string` để ra câu thông báo.

## 6. Phần Chú Ý Và Lỗi Hay Gặp

- **Không kiểm tra dữ liệu trước khi gọi** `stoi()`**/**`stod()`: đây là lỗi nghiêm trọng nhất (xem lại Ví dụ 4) — nếu dữ liệu đến từ người dùng và có khả năng không phải số hợp lệ, chương trình có nguy cơ bị dừng đột ngột. Với các chương trình thực tế cần độ an toàn cao hơn, nên xem xét cách bắt lỗi (kiến thức nâng cao hơn, sẽ học ở phần xử lý ngoại lệ).
- **Nhầm lẫn** `stoi()` **(cho số nguyên) và** `stod()` **(cho số thực)**: dùng `stoi()` với một chuỗi có phần thập phân (như `"8.75"`) sẽ chỉ lấy được phần nguyên trước dấu chấm, làm mất dữ liệu quan trọng — luôn chọn đúng hàm tương ứng với kiểu dữ liệu bạn cần.
- **Ngạc nhiên với định dạng mặc định của** `to_string()` **với số thực**: như đã thấy ở Ví dụ 1, `to_string(8.5)` cho ra `"8.500000"` chứ không phải `"8.5"` — cần lưu ý điều này khi hiển thị thông báo cho người dùng, tránh gây hiểu lầm về độ chính xác của con số.
- **Nghĩ rằng** `stoi()` **yêu cầu toàn bộ chuỗi phải là số**: như đã minh chứng ở Ví dụ 2, `stoi()` chỉ cần chuỗi **bắt đầu** bằng một số hợp lệ, phần còn lại phía sau sẽ bị bỏ qua mà không báo lỗi — điều này có thể dẫn đến kết quả không như mong đợi nếu bạn không kiểm tra kỹ dữ liệu đầu vào.
- **Quên rằng số quá lớn cũng gây lỗi**: chuỗi như `"99999999999"` toàn là chữ số nhưng vượt quá phạm vi của `int`, nên `stoi()` ném lỗi `std::out_of_range` và chương trình cũng dừng nếu không được xử lý.
- **Cố dùng phép** `+` **giữa** `string` **và số trực tiếp mà quên chuyển đổi**: viết `"Tuoi: " + tuoi` (với `tuoi` là kiểu `int`) không cho ra chuỗi như mong muốn (trình biên dịch báo lỗi hoặc cảnh báo), vì toán tử `+` không nối chuỗi với số — luôn nhớ bọc số bằng `to_string()` trước khi nối vào chuỗi.
