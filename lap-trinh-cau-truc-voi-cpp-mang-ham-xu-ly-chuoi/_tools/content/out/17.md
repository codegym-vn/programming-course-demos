# So Sánh Chuỗi (String Comparison)

## 1. Mục Tiêu Bài Học

- Hiểu bản chất: so sánh hai chuỗi bằng `==`, `!=`, `<`, `>` không phải so sánh **độ dài**, mà so sánh theo **thứ tự từ điển (lexicographic)** — dựa trên mã ASCII của từng ký tự.
- Nắm vững cú pháp: dùng trực tiếp các toán tử so sánh quen thuộc với `std::string`, không cần gọi hàm riêng nào cả.
- Hiểu đúng cơ chế so sánh: C++ so sánh lần lượt từng ký tự một, và dừng lại ngay khi tìm được điểm khác biệt đầu tiên.
- Ứng dụng được vào bài toán thực tế: sắp xếp danh sách tên theo thứ tự alphabet.

## 2. Giới Thiệu

Bạn đã quen thuộc với việc so sánh hai con số bằng `==`, `<`, `>` — nhưng so sánh hai chuỗi thì sao? May mắn thay, `std::string` trong C++ hỗ trợ đầy đủ các toán tử so sánh này, dùng được ngay mà không cần học thêm cú pháp mới.

Tuy nhiên, đây cũng chính là nơi dễ gây hiểu lầm nhất: rất nhiều người mới học nghĩ rằng `"apple" < "banana"` là so sánh xem chuỗi nào "ngắn hơn" hoặc "đứng trước" theo cảm tính — trong khi thực chất, C++ đang so sánh **từng ký tự một**, dựa trên mã ASCII của chúng, giống hệt cách một cuốn từ điển sắp xếp các từ theo thứ tự chữ cái. Hiểu đúng cơ chế này sẽ giúp bạn tránh được những bất ngờ khó chịu khi kết quả so sánh không như mong đợi.

## 3. Khái Niệm

- **So sánh theo thứ tự từ điển (Lexicographic Comparison)**: cách so sánh hai chuỗi bằng cách xét lần lượt từng cặp ký tự tương ứng, từ trái sang phải, cho đến khi tìm thấy cặp ký tự đầu tiên khác nhau — chuỗi nào có ký tự "nhỏ hơn" tại vị trí đó sẽ được coi là "nhỏ hơn".
- **Mã ASCII**: mỗi ký tự đều tương ứng với một con số cụ thể trong bảng mã ASCII — việc so sánh ký tự thực chất là so sánh những con số này. Một điểm quan trọng cần nhớ: các chữ cái **in hoa** (`A`-`Z`, mã 65-90) luôn có mã ASCII **nhỏ hơn** các chữ cái **in thường** (`a`-`z`, mã 97-122).
- **Trường hợp một chuỗi là tiền tố của chuỗi kia**: nếu toàn bộ một chuỗi ngắn hơn trùng khớp với phần đầu của chuỗi dài hơn (ví dụ `"Nam"` và `"Nam Anh"`), chuỗi **ngắn hơn** sẽ luôn được coi là "nhỏ hơn".

## 4. Giải Thích

### 4.1. So Sánh Bằng Và Khác — ==, !=

```cpp
string ten1 = "Nam";
string ten2 = "Nam";

if (ten1 == ten2) {
    cout << "Hai chuoi giong nhau!" << endl;
}
```

Hai chuỗi được coi là bằng nhau khi và chỉ khi chúng có **cùng độ dài** và **từng ký tự ở mọi vị trí đều giống hệt nhau** — chỉ cần khác nhau một ký tự duy nhất (kể cả khác hoa/thường), hai chuỗi sẽ được coi là khác nhau.

### 4.2. So Sánh Lớn Hơn, Nhỏ Hơn — <, >

```cpp
string apple = "apple";
string banana = "banana";

cout << (apple < banana) << endl;   // In ra 1 (dung), vi 'a' < 'b'
```

C++ so sánh ký tự đầu tiên của mỗi chuỗi: `'a'` (của `"apple"`) có mã ASCII nhỏ hơn `'b'` (của `"banana"`), nên `"apple"` được coi là "nhỏ hơn" — quá trình so sánh dừng lại ngay tại đây, không cần xét thêm các ký tự phía sau.

### 4.3. Lưu Ý Quan Trọng: So Sánh Theo Mã ASCII, Không Theo Trực Giác Bảng Chữ Cái

Vì chữ in hoa có mã ASCII nhỏ hơn chữ in thường, một chuỗi bắt đầu bằng chữ in hoa luôn được coi là "nhỏ hơn" bất kỳ chuỗi nào bắt đầu bằng chữ in thường — bất kể vị trí của các chữ cái đó trên bảng chữ cái thông thường.

## 5. Ví Dụ

Toàn bộ output dưới đây được lấy từ lần biên dịch và chạy thử thực tế.

### Ví dụ 1: So sánh bằng và khác (Mục tiêu: nắm cú pháp cơ bản nhất)

```cpp
string ten1 = "Nam";
string ten2 = "Nam";
string ten3 = "Lan";

cout << "ten1 == ten2: " << (ten1 == ten2) << endl;
cout << "ten1 == ten3: " << (ten1 == ten3) << endl;
cout << "ten1 != ten3: " << (ten1 != ten3) << endl;
```

**Output đã kiểm chứng:**

```
ten1 == ten2: 1
ten1 == ten3: 0
ten1 != ten3: 1
```

### Ví dụ 2: So sánh lớn hơn, nhỏ hơn với chữ cái đầu khác nhau (Mục tiêu: nắm cơ chế so sánh cơ bản)

```cpp
string apple = "apple";
string banana = "banana";

cout << "apple < banana: " << (apple < banana) << endl;
cout << "apple > banana: " << (apple > banana) << endl;
```

**Output đã kiểm chứng:**

```
apple < banana: 1
apple > banana: 0
```

### Ví dụ 3: So sánh theo mã ASCII — không theo trực giác bảng chữ cái (Mục tiêu: tránh hiểu lầm phổ biến nhất)

```cpp
string chuHoa = "Zebra";
string chuThuong = "apple";

cout << "\"Zebra\" < \"apple\": " << (chuHoa < chuThuong) << endl;
cout << "Ma ASCII cua 'Z': " << (int)'Z' << endl;
cout << "Ma ASCII cua 'a': " << (int)'a' << endl;
```

**Output đã kiểm chứng:**

```
"Zebra" < "apple": 1
Ma ASCII cua 'Z': 90
Ma ASCII cua 'a': 97
```

Đây là kết quả rất dễ gây bất ngờ: dù chữ `Z` đứng **sau cùng** trong bảng chữ cái, `"Zebra"` vẫn được coi là **nhỏ hơn** `"apple"` — vì `Z` (in hoa, mã ASCII `90`) có giá trị nhỏ hơn `a` (in thường, mã ASCII `97`). C++ hoàn toàn không quan tâm đến "thứ tự bảng chữ cái" theo cách con người thường nghĩ, nó chỉ so sánh mã số của từng ký tự.

### Ví dụ 4: Trường hợp một chuỗi là tiền tố của chuỗi kia (Mục tiêu: hiểu quy tắc khi một chuỗi "hết ký tự" trước)

```cpp
string ten1 = "Nam";
string ten2 = "Nam Anh";

cout << "\"Nam\" < \"Nam Anh\": " << (ten1 < ten2) << endl;
```

**Output đã kiểm chứng:**

```
"Nam" < "Nam Anh": 1
```

Ba ký tự đầu của cả hai chuỗi hoàn toàn giống nhau (`"Nam"`), nhưng `"Nam"` đã "hết ký tự" trong khi `"Nam Anh"` vẫn còn — trong trường hợp này, chuỗi ngắn hơn (đã hết trước) luôn được coi là nhỏ hơn.

### Ví dụ 5: Ứng dụng thực tế — sắp xếp danh sách tên theo alphabet (Mục tiêu: ứng dụng vào bài toán quen thuộc)

```cpp
string danhSach[5] = {"Nam", "Binh", "An", "Cuong", "Duc"};
int n = 5;

for (int i = 0; i < n - 1; i++) {
    for (int j = 0; j < n - 1 - i; j++) {
        if (danhSach[j] > danhSach[j + 1]) {
            string temp = danhSach[j];
            danhSach[j] = danhSach[j + 1];
            danhSach[j + 1] = temp;
        }
    }
}

for (int i = 0; i < n; i++) {
    cout << (i + 1) << ". " << danhSach[i] << endl;
}
```

**Output đã kiểm chứng:**

```
1. An
2. Binh
3. Cuong
4. Duc
5. Nam
```

Kỹ thuật Bubble Sort đã học ở phần Mảng hoàn toàn áp dụng được cho mảng chuỗi — chỉ cần thay điều kiện so sánh số (`>`) bằng đúng toán tử so sánh chuỗi tương tự, thuật toán vẫn hoạt động chính xác, sắp xếp đúng thứ tự alphabet.

### Xem so sánh từng ký tự, từng bước

Bấm **Bước tiếp** để thấy hai chuỗi xếp thẳng cột, dưới mỗi ô là mã ASCII:

- Tab **==, != và < với "apple"/"banana"**: các cột giống nhau tô xanh; cột khác nhau đầu tiên tô vàng kèm phép so mã; các cột phía sau mờ đi vì không cần xét.
- Tab **Bẫy chữ hoa và tiền tố**: chuỗi hết trước hiện ô "(hết)"; thêm hai trường hợp `"z" > "apple"` (dù ngắn hơn) và `"Nam" == "nam"` (khác nhau vì mã `78` và `110`).
- Tab **Sắp xếp danh sách tên**: ở lượt đầu, mỗi lần so hai tên liền nhau đều thấy phép so cột 0; `"Nam"` thắng bốn lần liên tiếp nên bị đẩy dần về cuối mảng.

## 6. Phần Chú Ý Và Lỗi Hay Gặp

- **Nghĩ rằng so sánh chuỗi là so sánh độ dài**: đây là hiểu lầm phổ biến nhất — `"Hello"` không "lớn hơn" `"Hi"` vì dài hơn; việc so sánh hoàn toàn dựa trên nội dung ký tự theo thứ tự từ điển, độ dài chỉ có ý nghĩa khi một chuỗi là tiền tố của chuỗi kia (xem lại Ví dụ 4).
- **Bất ngờ khi so sánh chuỗi có chữ hoa lẫn chữ thường**: như đã minh chứng ở Ví dụ 3, chữ in hoa luôn có mã ASCII nhỏ hơn chữ in thường — nếu cần so sánh "không phân biệt hoa/thường" (ví dụ khi sắp xếp tên mà không quan tâm chữ hoa/thường), cần chủ động chuyển cả hai chuỗi về cùng dạng (toàn chữ hoa hoặc toàn chữ thường) trước khi so sánh.
- **Dùng `==` để so sánh chuỗi nhưng quên rằng nó phân biệt hoa/thường tuyệt đối**: `"nam" == "Nam"` sẽ luôn cho kết quả sai (không bằng nhau), dù về mặt ý nghĩa hai chuỗi có thể được coi là "cùng một cái tên" — cần xử lý chuẩn hóa chữ hoa/thường trước nếu muốn so sánh theo nghĩa này.
- **Nhầm lẫn chiều so sánh trong điều kiện sắp xếp**: như Ví dụ 5, dùng `danhSach[j] > danhSach[j + 1]` để sắp xếp tăng dần (giống hệt logic sắp xếp số) — đảo ngược dấu so sánh sẽ cho ra kết quả sắp xếp giảm dần.
- **Quên rằng C++ dừng so sánh ngay khi tìm thấy ký tự khác biệt đầu tiên**: điều này có nghĩa hai chuỗi rất dài nhưng chỉ khác nhau ở ký tự đầu tiên vẫn được so sánh cực kỳ nhanh chóng — không cần lo lắng về hiệu năng khi so sánh các chuỗi dài trong thực tế.
